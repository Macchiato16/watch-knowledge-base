# 动力存储

**动力存储（Power Reserve）** 是机械腕表业务沟通中使用频率最高的概念之一。新人首先需要分清“**满链走时时长**”与“**盘面动力存储显示功能**”两个关联但不同的概念，再学会通过表盘上的“油表/电量表”快速判断机芯当前的上链状态。

---

## 一、两个必须分清的基础概念

1. **动力存储时长（机芯参数，几乎所有机械表都有）**：
   - 指机械腕表内部发条盒完全上满链后，静置不戴时能够持续走时的总时间（例如常见 42–48 小时、70 小时，甚至长动力款的 7 日以上）。
   - 如果一只表标称“70 小时动储”，但盘面上并没有任何额外指示针，它只是拥有较长的续航能力，**并不代表它带有动力存储显示功能**。
2. **动力存储显示（Power Reserve Indicator，简称“动储显示”）**：
   - 指在表盘正面或机芯背面专门设计的一套**剩余能量指示装置**，作用就像汽车仪表盘的油表或手机电量条——直观告诉佩戴者“发条还剩多少能量、是否快要停表了”。
   - 在百达翡丽官方机芯命名中，带有动力存储显示功能通常以法文缩写 **IRM**（*Indicateur de Réserve de Marche*）标识。

---

## 二、盘面常见表现形式

### 1. 扇形指针刻度（最经典主流）

在表盘上划分出一块扇形（弧形）区域，标注小时数（如 `48`、`36`、`12`）或百分比 / `UP–DOWN` / `满–空` 标记，由一根小指针在弧形区间内来回摆动。上链时指针向高刻度移动，走时消耗时指针缓缓回落。

- **典型代表**：**百达翡丽 Nautilus（鹦鹉螺）Ref. 5712** 是整个行业最具辨识度的扇形动储代表之一，其 10–11 点位扇形动储盘用数字 `48`、`36`、`12` 配合红色警示圆点，提示约 48 小时最大动力储备与低电量预警。

![百达翡丽 Nautilus 5712/1R 扇形动力存储显示](/images/general/functions/power-reserve/patek-5712-1r-power-reserve.jpg)

*图：百达翡丽 Nautilus Ref. 5712/1R-001 玫瑰金腕表。观察表盘左上角 10–11 点钟位置，可见清晰的扇形动力存储指示（刻度由 `48`、`36`、`12` 延伸至红色低动力警示圆点）；同时注意 7 点位副盘还集成了指针式日历与月相功能。*

### 2. 理查米尔盘面弧形 / 镂空动储显示

**理查米尔（Richard Mille）** 极其擅长将动力存储指示融入镂空建筑感盘面中，让机械运转状态一目了然。

- **典型代表**：**理查米尔 RM 030** 在表盘左侧 8–10 点位设有醒目的红蓝配色弧形 **55 小时动力存储指示**（刻度 `0` 至 `50` 余小时），并在 12 点位下方配有独家的 **离合式自动陀状态窗（ON / OFF）**——当动储达到约 50 小时接近满链时，自动陀会自动脱开停止上链，防止发条过度紧绷磨损；当动力消耗回落到约 40 小时以下时，自动陀重新啮合上链。

![理查米尔 RM 030 盘面弧形动力存储显示](/images/general/functions/power-reserve/richard-mille-rm030.jpg)

*图：理查米尔 RM 030 自动上链腕表。观察表盘左侧 8–10 点位红蓝弧形刻度区，即为 55 小时动力存储显示（当前指针靠近 `0` 位置，提示发条接近耗尽）；12 点位下方的小视窗用于指示离合自动陀的啮合/脱开状态。*

### 3. 圆形副盘、线性/滚筒指示与背透侧动储

除了最常见的扇形指针，在高级制表中还能见到另外三种形态：

- **圆形副盘式**：使用一个完整的 360 度小圆盘（类似小秒盘）来指示剩余动力天数或小时数，常见于多日链长动力表款。
- **线性 / 滚筒指示**：用直线滑块、垂直条形槽或旋转滚筒直接显示百分比或剩余小时数，常见于前卫现代设计腕表。
- **背透侧动储指示**：部分追求正面盘面极简对称的正装表或长动力手动表，会把扇形或弧形动力存储指针设计在**表背机芯夹板上**，翻转腕表透过蓝宝石背透底盖即可查看剩余动力。

## 三、常见动储显示形式速查表

| 表现形式 | 盘面视觉特征 | 常见代表与适用场景 |
| --- | --- | --- |
| **扇形指针刻度** | 弧形刻度（小时数或红点预警）+ 摆动小指针 | 百达翡丽 5712、5146 等经典复杂款 |
| **镂空弧形动储** | 弧形刻度悬浮于镂空夹板之上，常伴功能状态窗 | 理查米尔 RM 030 等现代先锋运动款 |
| **圆形副盘式** | 独立小圆盘，指针指示剩余天数或小时 | 多日链长动力腕表 |
| **线性 / 滚筒式** | 直线条形进度条或立体滚筒数字 | 现代概念表或特殊显示款式 |
| **背透侧动储** | 正面无任何动储刻度，翻转看表背夹板指针 | 注重正面极简美学的正装或手动表 |

## 四、二手业务沟通与实操常识

1. **收表验表：用动储指针辅助判断上链效率与机芯状态**：
   - 拿到一只带有动储显示的腕表时，先记录动储指针当前位置。若指针处于低位（如 0 或红点区），可尝试顺时针手动旋转 [表冠](/general/structure/#part-crown) 上链 20–30 圈，观察动储指针是否随着上链动作**稳步、顺滑地向满链方向爬升**。
   - 如果拧了很多圈指针毫无反应，或上满后静置不到半天动储指针就迅速掉到底并停表，往往提示发条盒或上链轮系可能存在故障，需交由专业技师进一步检测。
2. **手动上链表款的“满链手感”提醒**：
   - 自动上链腕表（如百达翡丽 5712、理查米尔 RM 030）内部有防过紧打滑机构，上满链后继续拧表冠会有轻微“咔哒”打滑感，不会拧断发条；
   - 但若是**纯手动上链**且带动力存储的腕表，上链至接近满格时手感会明显变沉、拧不动，此时应立即停止继续用力拧表冠，切勿蛮力硬拧。
3. **区分“空链停表”与“真故障”**：
   - 展柜陈列或客户寄卖的腕表长期未佩戴，动储指针回落归零属于正常耗尽能量，并非机芯损坏；业务人员在向客户展示前可提前补足一定动力，让腕表走时与动储指针处于健康工作区间。
