# 腕表业务知识库介绍

本知识库面向公司全体岗位员工，用于新人入职系统学习二手腕表业务基础，并支持日常工作随时检索查阅。

## 知识结构与学习顺序

网站内容划分为 **通用知识** 与 **品牌知识** 两大板块。建议新人按以下路径循序阅读：

1. **通用知识（建立基础框架）**
   - [认识腕表结构](/general/structure/)：通过三维交互演示与图文对应，掌握表壳、机芯及关键运动部件的名称、位置与作用。
   - **腕表材质**（待补充）：先认识精钢、陶瓷、白金、黄金、玫瑰金、铂金六种常见材质及直观差别。
   - **腕表功能**（待补充）：先掌握日期、计时、年历、动力存储、双时区五项基础认知，再按需深入理解万年历、三问、双秒追针计时、陀飞轮与天文星象。
   - **腕表行业生态**（待补充）：理解品牌定位、一二级市场流通与二手业务的关系。
2. **品牌知识（结合核心业务深入）**
   - 围绕公司业务重心，以 **百达翡丽（Patek Philippe）**、**理查米尔（Richard Mille）** 为核心重点，兼顾 **劳力士（Rolex）**，少量涉及 **爱彼（Audemars Piguet）**。
   - 按各品牌的「品牌材质」「型号解读」「热门系列与具体腕表」「关联型号与对比记忆」逐步展开。

## 阅读约定

- **术语与俗称对照**：正文以规范名称为主，同时列出二级市场常用俗称（如“把头”“五珠带”“手雷”等），均可通过右上角搜索框直接检索。
- **事实与经验区分**：客观结构参数与市场偏好观察分开说明；型号编码解读仅列出规则可确切推断的信息，不把需查资料核对的项目当作编码必然结论。
