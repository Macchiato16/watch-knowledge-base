# 理查米尔型号解读（Reference Guide）

在理查米尔（Richard Mille）的日常收售、电话询价与保卡核验中，型号编码不仅是识别表款家族的第一把钥匙，更是拆穿“拼装表壳”“后镶钻”与“假保卡”的核心防线。与传统瑞士名表不同，理查米尔自 2001 年创立以来，形成了兼具**机械结构提示**与**法语/英语复合材质缩写**的独特编码语言。

::: warning 核心原则：区分「100% 可读」与「必须核对保卡/实物」
理查米尔型号体系与百达翡丽的“四段强制统一公式”截然不同：它经历了从早期**单段三位数（`RM 0xx`）**向现代**双段连字符家族体系（`RM xx-xx`）**的代际演进，且表壳材质/功能常以附加英文或法语缩写（如 `CA`、`FQ`、`ATZ`、`TZP`、`TI`、`RG`、`WG`、`AO`）体现在保卡、表背铭文与官方档案中。

业务评估时必须严格区分**「单凭型号与材质后缀 100% 可读出的信息」**与**「必须核对原厂保卡 / 实物细节 / 官方档案才能确认的信息」**——严禁靠数字大小盲猜复杂程度，更严禁靠口头简称盲报带钻款或运动员联名款价格！
:::

## 一、两代型号语法演进与“前导零”官方书写铁律

理查米尔在 2001 年起步阶段采用单段三位数编号；约自 **2011 年起**，随着产品家族不断横向扩展，品牌全面转向双段连字符体系，形成如今并存的两代官方语法：

```text
第一代（单段三位数，2001 – 约 2010 年代初）：
  [RM] + [空格] + [三位前导零数字] (+ 保卡材质/功能后缀)
   RM       055                         (如 RM 011、RM 027、RM 030、RM 035、RM 055)

第二代（双段连字符体系，约 2011 年至今绝对主力）：
  [RM] + [空格] + [家族主号 xx] + [- 代际/细分号 xx] (+ 保卡材质/功能后缀)
   RM               07              -01                 ATZ-RG
   RM               35              -03                 CA-FQ
   RM               67              -01                 AO TI
```

### 1. 第一代单段三位数体系（2001 年 – 约 2010 年代初）

- **标准语法**：`RM 0xx`，即 `RM` 后固定保留一个半角空格，再接**带前导零的三位数字**（早期个别超百号亦保持三位数字）。
- **代表型号**：`RM 011`（飞返计时年历传奇）、`RM 027`（初代纳达尔陀飞轮）、`RM 030`（可离合摆陀自动）、`RM 035`（初代纳达尔手动镁铝合金“小牛”）、`RM 037`、`RM 055`（Bubba Watson 手动镂空）。
- **延续特点**：即使进入 2010 年代中期，部分以初代平台延续迭代的经典款（如 `RM 055`、早期 `RM 037`）仍沿用单段三位数写法，并未强行改写为 `-01`。

### 2. 第二代双段连字符体系（约 2011 年至今绝对主力）

- **第一段数字 `xx`（产品家族 / 壳型与定位平台）**：锁定表款所属的核心家族与人体工学壳型平台（如 `07`、`11`、`27`、`35`、`65`、`67`、`72`）。本知识库设置 **`07 / 11 / 35 / 55 / 65 / 67 / 72`** 七大教学分组，底层依据正是这套家族平台编号。
- **连字符后第二段 `-01 / -02 / -03 / -04 / -05`（家族内部代际演进或细分定位升级）**：同一家族数字下，连字符后的两位数字代表机械架构迭代、材质级别跨越或使用场景分化：
  - **11 大号飞返计时年历家族进化**：初代单段 `RM 011`（流线侧壳 + `RMAC1`）→ `RM 11-02`（叠加双时区 GMT 功能与 9 点位侧键）→ `RM 11-03`（换装 `RMAC3`、升级纵向凹槽空气动力学表壳与赛车轮毂表冠）→ `RM 11-05`（灰色 Cermet 金属陶瓷表圈配 GMT 飞返计时限量版）。
  - **35 纳达尔“小牛”三代演进**：`RM 35-01`（手动上链、Carbon TPT® 碳壳）→ `RM 35-02`（首次升级为自动上链、Cal. RMAL1 透底）→ `RM 35-03`（新增 7 点位按键控制专利“蝶形摆陀”、Cal. RMAL2）。
  - **67 超薄酒桶定位分化**：`RM 67-01`（7.75 mm 都市超薄、带 5 点位日历与 2 点位功能指示）→ `RM 67-02`（取消日历与功能指示，极限镂空减重至约 32 克，专注极限运动联名）。
  - **07 女装家族矩阵升级**：`RM 07-01`（品牌现代女装核心主力，自动可变几何摆陀）→ `RM 07-02`（全蓝宝石水晶表壳高珠/超豪华定位）→ `RM 07-04`（品牌首款女性专属超轻运动表，Quartz TPT® 壳配高抗震架构）。

### 3. 报价与合同书写红线（绝不擅自统一前导零！）

::: danger 书写红线：前导零多一位或少一位，直接触发假卡警报！
日常口语交流中，同行常把 `RM 055` 喊成“理查 55”，把 `RM 07-01` 喊成“07”。但在**原厂保卡、表背铭文、报价单与买卖合同**中，两代型号的前导零位数有绝对刚性规定，**绝不可擅自统一格式**：
- **`RM 055`** 永远保留三位前导零且**无 `-01`**（官方绝不存在 `RM 55` 或 `RM 055-01`）；
- **`RM 07-01`** 永远使用两位前导零 `07` 加 `-01`（官方绝不写作 `RM 007-01` 或 `RM 7-01`）。

如果在验表时发现保卡印刷格式违背上述官方命名法（例如出现 `RM 55` 或 `RM 007-01`），可直接判定为异常印刷或假卡！
:::

## 二、逐段深度拆解：数字编号逻辑与保卡高频材质/功能缩写全表

### 1. 数字编号的真相：破除“数字越大越贵/越复杂”迷思

新手最常犯的错误，是以为 `RM 67` 比 `RM 27` 数字大，就一定更复杂或更贵。事实上，理查米尔的主编号**大体按研发立项时间线推进**，并穿插少量文化寓意或特定主题编号（例如刻意避开部分数字，或选用 `RM 055`、`RM 088` 笑佛自动陀飞轮等吉祥/特定序列），**数字大小与机械复杂度、公价高低毫无正相关**：

- **硬核反例 1**：`RM 027` 与 `RM 27-04` 编号仅 `27`，却是单价千万元级的纳达尔极致轻量化陀飞轮神物；而数字大得多的 `RM 67-01`（`67`）则是基础自动超薄三针日历款。
- **硬核反例 2**：同在 `07` 家族内部，`RM 07-01` 是百万元级女款自动主力，而仅差一位的 `RM 07-02` 却因全蓝宝石水晶表壳跃升至数百万元级高定行列。

### 2. 保卡与表背铭文高频字母后缀速查表

在二手电话询价与核对保卡时，紧跟在数字型号后面的英文或法语缩写，是锁定表壳材质与上链方式的“核心密码”：

| 缩写代码 | 英文 / 法语全称 | 对应材质或工艺含义 | 代表型号与实操备注 |
| --- | --- | --- | --- |
| **`TI` / `Ti`** | *Titanium*（五级钛合金） | **五级钛合金**（Grade 5 Titanium） | 如 `RM 67-01 AO TI`、`RM 030 AO TI`；轻盈耐腐蚀，常见喷砂或拉丝处理 |
| **`RG` / `5N`** | *Rose Gold* / 5N 红金 | **18K 红金 / 玫瑰金** | 如 `RM 72-01 RG`、`RM 07-01 RG`；色泽偏暖红，表背带 Au750 贵金属印记 |
| **`WG`** | *White Gold* | **18K 白金** | 如 `RM 67-01 WG`、`RM 037 WG`；密度与压手感远高于外观相近的钛金属 |
| **`PT`** | *Platine / Platinum* | **950 铂金** | 多见于早期限量或高端正装/复杂款（如早期 `RM 011 PT`），现代款极罕见 |
| **`CA` / `NTPT`** | *Carbon TPT®* | **薄层复合碳纤维** | 如 `RM 65-01 CA`、`RM 35-01`；标志性哑光黑灰大马士革层压纹路 |
| **`FQ`** | ***Fibres de Quartz***（法语） | **Quartz TPT® 石英纤维** | **新人最易懵的高频法语缩写！**看到 `FQ`（如 `RM 35-02 FQ`）秒懂是白色或高饱和彩色石英纤维壳 |
| **`ATZ`** | 氧化铝增韧氧化锆陶瓷 | **高压增韧白色陶瓷** | 如 `RM 055`、`RM 07-01 ATZ`；莫氏硬度极高、极难刮花且永不变色 |
| **`TZP`** | 四方氧化锆多晶陶瓷 | **黑陶瓷或彩色微喷砂陶瓷** | 常带颜色后缀，如 `TZP-N`（黑陶，*Noir*）、`TZP-PK`（粉陶）、`TZP-BL`（蓝陶） |
| **`Cermet`** | *Ceramic + Metal* | **金属陶瓷**（灰色/暗色金属质感陶瓷） | 兼具陶瓷硬度与金属光泽，多见于高抗刮运动表圈（如 `RM 11-05`） |
| **`Saphir` / `Sapphire`** | *Sapphire Crystal* | **整块蓝宝石水晶表壳** | 如 `RM 07-02`、`RM 56-02`；单壳加工工时数以千小时计，千万/数百万级标识 |

关于 Carbon TPT®（30 微米 45° 层压）、Quartz TPT® 与各类陶瓷的物理特性及真伪手感对比，请参阅 [理查米尔品牌材质](/brands/richard-mille/materials) 与 [理查米尔品牌工艺](/brands/richard-mille/craftsmanship) 专章。

### 3. 三明治表壳“双材质连写”语法（防拼装表核心技能）

理查米尔经典酒桶表壳由**「前表圈 + 中层表壳 + 底盖」**三明治结构组成，上下圈与中壳常采用不同材质混搭。当上下圈与中壳材质不同时，保卡与档案型号会使用**连字符连接两组材质代码**：

- **`RM 07-01 ATZ-RG`**：`ATZ`（高压增韧白陶瓷前圈与底盖）+ `RG`（18K 红金中层表壳）。
- **`RM 67-02 CA-FQ` / `FQ-CA`**：`CA`（Carbon TPT® 碳纤维）与 `FQ`（Quartz TPT® 彩色石英纤维）复合搭配。
- **`RM 65-01 RG-CA`**：`RG`（18K 红金前圈/底盖）+ `CA`（Carbon TPT® 碳纤维中壳）。

::: tip 实战防坑：一眼拆穿“换壳拼装表”
在二级市场，由于理查米尔前圈与中壳可单独拆卸，偶见不良商家将普通 `TI`（钛壳）或 `RG`（红金壳）私自更换为热门的 `ATZ` 白陶或 `CA` 碳纤维上下圈。核对保卡上的双材质连写代码（如 `ATZ-RG` vs `RG-CA` vs 纯 `TI`），能在第一时间识破货不对版的拼装表！
:::

### 4. 常见机芯与联名缩写

- **`AO`（*Automatic Winding*）**：自动上链标识。这是保卡上极为高频的法英混用代码，常见于 **`RM 030 AO TI`**、**`RM 07-01 AO RG`**、**`RM 67-01 AO TI`** 等标注中，用来明确该表款为自动上链版本。
- **`FM`（*Felipe Massa*）**：早期 F1 车手菲利佩·马萨联名标识，如经典初代 `RM 011 FM`。
- **`RAFA`（*Rafael Nadal*）**：纳达尔专属标识，常刻印于 `27` 与 `35` 系列盘面或底盖铭文中。
- **`LMC`（*Le Mans Classic*）**：勒芒经典赛限量版缩写，多采用标志性绿白赛车条纹配色（如 `RM 029 LMC`、`RM 72-01 LMC`）。

## 四、专章重点汇总表：「编码可直接推断项」vs「必须查资料 / 核对保卡项」

在收售评估、电话报价与客户沟通中，请严格遵守以下判断边界，**绝不把无法编码读出的信息当作型号本身的确定结论**：

| 判断类别 | 具体项目 | 能否单凭型号/后缀确认 | 判定依据与实操说明 |
| --- | --- | --- | --- |
| **✓ 可直接推断** | **所属产品家族与基础壳型** | **能** | 由主编号（如 `07`、`11`、`35`、`055`、`65`、`67`、`72`）直接锁定所属家族壳型与功能大类；但**数字大小不能代表复杂度或公价** |
| **✓ 可直接推断** | **同家族内部代际演进** | **能** | 双段体系的 `-01 / -02 / -03 / -04` 明确区分同系迭代（如 `RM 35-01` 手动 → `35-02` 自动 → `35-03` 蝶形摆陀） |
| **✓ 可直接推断** | **带后缀时的表圈与中壳材质** | **能** | `TI`、`RG`、`WG`、`CA`、`FQ`、`ATZ`、`TZP` 及双材质连写（如 `ATZ-RG`、`CA-FQ`、`RG-CA`）可 100% 锁定对应部件材质 |
| **✓ 可直接推断** | **是否标注自动上链（`AO`）** | **能** | 保卡出现 `AO` 即代表自动上链版本；无 `AO` 的早期单段款需结合型号目录确认手动或自动 |
| **⚠ 须查证核对** | **`FQ` / `TZP` 具体配色与运动员联名** | **不能** | **重大避坑**：同写 `RM 67-02 CA-FQ`（或 `FQ`），却对应巴尔希姆紫红、勒克莱尔白红、奥吉尔蓝、范尼凯克绿黄、意大利三色等十余种联名配色，**二级市场价差巨大**，必须看实物与保卡！ |
| **⚠ 须查证核对** | **是否原厂镶钻及镶钻规格** | **不能** | 理查米尔常规基础型号口头常统称 `RM 07-01 RG` 或 `RM 07-01 CA`，并不像百达翡丽那样强制带 `/200`、`/300` 尾码；**满钻、雪花镶嵌、中钻或素圈必须核对原厂保卡镶钻明细**，严防后镶钻！ |
| **⚠ 须查证核对** | **盘面内圈刻度配色与表带规格** | **不能** | 内圈法兰配色、时标颜色及随附橡胶/织物/链带类型与尺码（如 `RM 67-02` 弹性带尺码）均不体现在基础编码中 |
| **⚠ 须查证核对** | **准确出厂生产与激活年份** | **不能** | 表背壳号（Case Number）无法按公式反推生产年份，**准确年份必须核对原厂保卡上的出厂/激活日期** |
