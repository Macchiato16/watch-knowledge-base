# 看图识表总纲：理查米尔 14 款核心腕表三步特征锚点定位法

在理查米尔（Richard Mille）二手收售与日常估价实战中，新人最常遇到的痛点不是“背不出 `CRMA` / `RMAC` 机芯编号”，而是**“客户发来一张没有型号、没有保卡的酒桶镂空表照片，如何在 3 秒内准确报出官方型号，绝不把高溢价的自动款、陶瓷限量版或追针旗舰当成入门手动款错报价”**。

理查米尔七大业务核心教学分组（`07 / 11 / 35 / 55 / 65 / 67 / 72`）合计 **14 款核心型号**，看似全是“三片式酒桶 + 镂空机芯 + 花键螺丝”，实则每一款在**螺丝颗数、壳侧按键分布、盘面功能与背透结构**上都有极强的视觉铁律。只要掌握下面这套「三步视觉漏斗口诀」，看图就能一秒锁死型号。

## 一、三步视觉漏斗口诀（3 秒锁定理查米尔 14 款型号）

::: tip 新人实战口诀：先数螺丝 → 再摸侧键 → 最后看盘面/背透
1. **第一步：数正面表圈花键螺丝颗数（先劈出 8 颗阵营）**
   - **正面 8 颗花键螺丝**：直接锁定四大目标——**女装主力 `RM 07-01`**、**超薄双生花 `RM 67-01` / `RM 67-02`**，以及**初代镁铝合金标准版 `RM 035`**（注意：`RM 035` 后期 `Americas / Black Toro` 陶瓷限量版升级为 12 颗螺丝）。
   - **正面 12 颗花键螺丝**：覆盖其余全部主流运动与计时型号（`RM 07-04`、`11` 系列、`35-01 / 35-02 / 35-03`、`RM 055`、`RM 65-01`、`RM 72-01` 及 `RM 035` 美洲陶瓷限量版）。
2. **第二步：摸清壳侧功能按键分布（直接切分 6 大阵营）**
   - **光洁无侧键（仅右侧表冠）**：`RM 07-01`、`RM 035`、`RM 35-01`、`RM 35-02`、`RM 055`、`RM 67-01`、`RM 67-02`（共 7 款）。
   - **仅右侧 4 点位单按键**：女性超轻运动 **`RM 07-04`**（对应 5–6 点 `H / N / W` 指示）。
   - **左 7 点 + 右 2 点对称双键**：纳达尔蝶形摆陀旗舰 **`RM 35-03`**（`SPORT` 开关 + `SELECTOR` 档位键）。
   - **仅右侧双计时键（无左键）**：经典大号飞返 **`RM 011` / `RM 11-03`**，与紧凑自产飞返 **`RM 72-01`**。
   - **右侧双计时键 + 左 9 点单 GMT 键**：Cermet 金属陶瓷双时区飞返 **`RM 11-05`**。
   - **右双键 + 左 8 点快速上链 + 左 10 点追针（共 5 侧键）**：高振频双秒追针旗舰 **`RM 65-01`**。
3. **第三步：看盘面功能与背透/材质，精准断代防错价**
   - **极简双针（无秒针）**：中央有实心饰片 = `07-01`；全镂空 + `H/N/W` = `07-04`；有 5 点日历 + `W/D/H` = `67-01`；TPT 壳无日历 + 弹性带 = `67-02`。
   - **纯粹大三针无日历**：全镂空无数字（透底无摆陀）= `055`；留数字且带双侧键 = `35-03`；无侧键 9 点铭牌区隔——`RM 035`（标准镁铝密底）/ `35-01`（碳壳手动、实心 Carbon TPT® 密底）/ `35-02`（自动可变几何摆陀透底）。
   - **三大计时阵营**：12 点双窗大日历 + 4–5 点月份窗 = `11` 系列；3/8/11 大数字 + 蓝橙绿不对称副盘 = `72-01`；11 点垂直日历 + 多色编码 + 5 侧键 = `65-01`。
:::
