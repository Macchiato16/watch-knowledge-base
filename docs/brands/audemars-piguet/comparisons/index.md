## 一、三步视觉漏斗口诀（3 秒锁定爱彼 17 款热门型号）

::: tip 新人实战口诀：先定壳圈阵营 → 再看针数布局 → 最后查 12/6 点标与新老断代
1. **第一步：看壳型体量与表圈形态（一刀切出皇家橡树 vs 离岸型）**
   - **皇家橡树（纤薄一体八角壳带，无外露黑胶圈）**：
     - **素净八角无钻圈**（精钢 / 贵金属 / 霜金 / 钛 BMG）：覆盖 Jumbo 双针（`15202 / 16202`）、41mm 自动（`15500 / 15510`）、金属双摆轮镂空（`15407`）、41mm 计时（`26331 / 26239 / 26240`）、37mm 无钻（`15550`）与 33mm 石英（`67650`）；
     - **原厂 40 颗美钻表圈**（八角每边精确 5 颗 + 型号末位奇数 `1` + `.ZZ.`）：锁定 `15551`（37mm）与 `77451`（34mm）；
     - **全高科技陶瓷一体壳带**（CE 黑陶 / CD 夜色蓝陶 / CB 白陶）：锁定 `15416`（双摆轮镂空）、`26240CE`（全黑陶计时）与 `77350`（34mm 陶瓷配玫瑰金螺丝）。
   - **皇家橡树离岸型（厚重运动壳 + 表圈下外露厚黑色橡胶防水垫圈 + 一键快拆表带）**：
     - **10 点位多一颗旋入式潜水表冠**：锁定 42mm 离岸潜水表 **`15720`**；
     - **42mm 右侧大护桥计时按把**：锁定离岸飞返计时 **`26238`**；
     - **37mm 外露胶圈 + 原厂 32 颗大钻圈（每边 4 颗）+ 胶带**：锁定女装离岸计时 **`26231`**。
2. **第二步：看盘面针数、镂空与计时布局，细分跨系与机芯**
   - **极简双针（无中央秒针）+ 3 点日历**：仅存在于 39mm 超薄 Jumbo（`15202 / 16202`）与 33mm 石英密底女表（`67650`），一眼切出全部大三针款！
   - **中央大三针 + 3 点日历**：涵盖 `15500 / 15510 / 15550 / 15551 / 77350 / 77451 / 15720`。
   - **无表盘全镂空 + 7–8 点位横跨桥板同轴双摆轮**：锁定 `15407`（金属壳）与 `15416`（全陶瓷壳）。
   - **3/6/9 横向三眼计时 + 4:30 斜向日历**：涵盖皇家橡树计时（`26331 / 26239 / 26240`）与 37mm 离岸计时（`26231`）。
   - **12/9/6 纵向“左三眼”计时 + 3 点位放大日历**：全系唯一锁定 42mm 离岸大护桥计时 **`26238`**。
3. **第三步：看“12 点 / 6 点标 + 奇偶尾码 + 透底摆陀”，精准断代防坑**
   - **12 点位有无立体 AP 标生死线**：前代 `15500 / 26331 / 26239` 在 12 点位带有**立体 AP 金属标**；2022 年 50 周年换代新世代（`15510 / 26240 / 15550 / 15551 / 77451`）彻底取消 12 点 AP 标，改为 **24K 电铸金连体 `AUDEMARS PIGUET` 英文** 并升级递减薄链带（2022 产 `.01` 批次背透独享 `50 YEARS` 镂空摆陀）。
   - **39mm Jumbo 专属 6 点位 AP 标**：`15202`（`Cal. 2121` 轨环摆陀慢调日历）与 `16202`（`Cal. 7121` 快调日历）均将立体 AP 标置于 6 点位。
   - **奇偶尾位防后加钻与 67 vs 77 石英防错价**：末位偶数 `0`（如 `15550 / 77450`）为无钻素圈，末位奇数 `1` + `.ZZ.`（如 `15551 / 77451`）才是原厂钻圈；`67650` 为 33mm 双针密底石英，`77350 / 77451` 为 34mm 大三针透底自动机械。
:::
