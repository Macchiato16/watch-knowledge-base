# 劳力士宇宙计型迪通拿 Ref. 116518LN（老款 18K 黄金胶带迪“余文乐家族”）

**Ref. 116518LN** 是 2017 年起陆续换装 Oysterflex 胶带、服役至 **2023 年停产**的老款 **18K 黄金黑陶圈胶带迪通拿**。因为香港艺人余文乐曾佩戴其中的香槟金盘黑眼款（`116518LN-0048`）出席公开场合并引发全网疯抢，该系列在中文表圈被统称为**“余文乐迪通拿家族”**，全系共涵盖 6 大官方核心配置。

## 一、一眼特征盘点（视觉识别锚点）

1. **一体外露黑陶圈（无黄金包边）**：`116518LN` 最显著的断代特征是黑色 Cerachrom 陶瓷测速圈**外沿直接裸露，没有 18K 黄金外环包边**；外圈测速数字采用 PVD 黄金镀层填充。
2. **表耳固定 18K 黄金端头肩位**：型号第 5 位为 `1`，表耳之间铸造有不可拆卸的 18K 黄金一体肩位，专配黑色 Oysterflex 橡胶带，**无法改装全金蚝式链带**。
3. **18K 黄金 Triplock 三扣锁表冠**：表冠皇冠标志下方呈现**中间圆点明显更大的三圆点（`• 🅞 •`）**，代表贵金属三扣锁防水结构。
4. **实心密底与 Easylink 表扣**：采用全封闭 18K 黄金实心底盖（无透底），Oysterflex 胶带配 18K 黄金 Oysterlock 保险扣及 `5 mm` Easylink 易调链节（尚未升级 2023 新款的 Glidelock 滑动微调扣）。

## 二、功能盘点与操作逻辑

`116518LN` 全系搭载 **`Cal. 4130`** 自产自动计时机芯：

| 核心维度 | 官方规格与实战说明 |
| --- | --- |
| **表壳材质与直径** | `40 mm` 18K 黄金（尾码 `8`，自有铸造所 `Au750` 黄金）；详见 [劳力士材质专章](/brands/rolex/materials) |
| **机芯型号** | `Cal. 4130` 自动上链机械计时机芯（Parachrom 蓝铌游丝、导柱轮 + 垂直离合） |
| **走时与动储** | 超卓天文台认证（`-2 / +2 秒/日`），约 **72 小时**动力储存 |
| **防水深度** | `100 米 / 330 英尺`（18K 黄金 Triplock 三扣锁表冠 + 旋入式计时按把） |
| **表带与表扣** | 黑色 Oysterflex 橡胶包覆钛镍合金片，18K 黄金 Oysterlock 扣 + `5 mm` Easylink；详见 [劳力士表带专章](/brands/rolex/bracelets) |

### 操作逻辑要点

- **表冠单档调时**：逆时针旋松 Triplock 表冠后，0 档可直接手动补链；**本款无日历功能，拉出仅有 1 档**（停秒调校时间）。
- **计时按钮严格先松再按**：按下 2 点（启动/暂停）或 4 点（归零）按钮前，**必须先逆时针旋松按钮锁紧螺帽**；计时走动期间**严禁直接按压 4 点归零**，须先按 2 点停止计时再归零（原理详见 [计时功能专题](/general/functions/complications/chronograph)）。操作完成后务必将表冠与按把螺帽旋紧锁死。

## 四、本款特殊之处深度详解

1. **定义“胶带金迪”黄金时代的“余文乐效应”**：虽然 `116518LN` 共有 6 种盘面，但 `-0048` 香槟金黑眼盘将 18K 黄金的贵气、黑陶圈的运动感与胶带的轻便完美融合，彻底打破了“全金迪通拿过于老气沉重”的刻板印象，直接奠定了劳力士 Oysterflex 胶带金迪成为年轻高净值群体硬通货的地位。
2. **一体式表耳不可改链带**：第 5 位 `1` 决定的固定黄金端头肩位意味着本款**终身只能使用 Oysterflex 胶带**，不可改装 `116508` 全金链带。
3. **同一黑盘下三款细节差异极易混淆**：`-0047`（实心香槟金眼 + 红分钟轨）、`-0043`（黑底细金环 + 黑分钟轨）、`-0078`（8 颗圆钻 + `15/30/45` 阿拉伯数字）同属黑盘阵营，收售报价时务必确认清楚具体配置尾码，切忌笼统报成“黑盘胶带金迪”。

## 五、二手收售核验与行情逻辑

::: warning 收表头号防坑红线：谨防“基础黑/白盘后换假余文乐盘 / 假陨石盘”！
`116518LN` 是整个迪通拿家族中**“换盘套利”重灾区**！由于 2020 年起新版深绿 NFC 保卡**不印 `-0048` / `-0076` 尾码**，部分不良商家会将行价最低的 `-0041` 白盘或 `-0043` 黑盘拆换高仿代用“余文乐香槟黑眼盘”或“仿陨石盘”充当高价款出售。收表时**必须核验随表白色条码吊牌（White Tag）尾码**；无白吊牌时，须在 10 倍镜下核查小表盘同心圆 CD 纹锐度、红色 `DAYTONA` 印刷边缘与夜光指针中轴装配压痕。
:::

1. **Oysterflex 胶带 `C–H` 尺码段与缓冲鳍**：不可裁剪，须核对双段胶带内侧模压字母（`C/D/E/F/G/H`）是否匹配买家腕围，以及缓冲鳍是否开裂老化。
2. **无包边外露黑陶圈微崩检查**：老款黑陶外沿直接暴露，必须绕圈细查有无微小崩缺；同时核验 2 点、4 点计时按钮螺帽拧动顺滑度。
3. **18K 黄金表扣与表耳抛光检查**：18K 黄金质地较软，重点检查表扣大面积拉丝面与表耳棱线是否被过度抛光变圆、表扣小皇冠是否被抛平。
