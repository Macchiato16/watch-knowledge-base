## 一、一眼特征盘点（视觉识别锚点）

1. **一体外露黑陶圈（无金属包边）**：2023 年停产前的 `116515LN` 采用一体成型黑色 Cerachrom 陶瓷外圈，**陶瓷圈外缘无 18K 玫瑰金包边环**，测速数字与刻度采用 PVD 玫瑰金镀层填充，暖金色刻度与黑陶形成强烈对比。
2. **表耳一体式固定金属肩位（第 5 位 `1` 铁律）**：型号第 5 位数字 `1` 锁死了其特殊壳型——表耳之间铸造有**一体成型不可拆卸的 18K 永恒玫瑰金端头肩位**，专用于衔接 Oysterflex 胶带，与可装全金链带的 `116505`（第 5 位 `0`）截然不同。
3. **玫瑰金 Triplock 三扣锁表冠**：表冠皇冠标志下方为 **3 个圆点且中间圆点明显更大（`• 🅞 •`）**，代表 18K 贵金属三扣锁防水系统。
4. **实心密底与 Easylink 折叠扣**：表背为全封闭 18K 永恒玫瑰金旋入式实心底盖（无透底），Oysterflex 胶带搭配 18K 永恒玫瑰金 Oysterlock 保险扣与 `5 mm` Easylink 易调链节。

## 二、功能盘点与操作逻辑

`116515LN` 搭载劳力士经典的 **`Cal. 4130`** 自产自动计时机芯：

| 核心维度 | 官方规格与实战说明 |
| --- | --- |
| **表壳材质与直径** | `40 mm` 18K 永恒玫瑰金（尾码 `5`，添加约 `2%` 铂金锁色抗氯防褪色）；详见 [劳力士材质专章](/brands/rolex/materials) |
| **机芯型号** | `Cal. 4130` 自动上链机械计时机芯（Parachrom 蓝铌游丝、导柱轮 + 垂直离合） |
| **走时与动储** | 超卓天文台认证（`-2 / +2 秒/日`），约 **72 小时**动力储存 |
| **防水深度** | `100 米 / 330 英尺`（18K 金 Triplock 三扣锁表冠 + 旋入式计时按把） |
| **表带与表扣** | 黑色 Oysterflex 高性能弹性体橡胶包覆钛镍合金片，18K 永恒玫瑰金 Oysterlock 扣 + `5 mm` Easylink；详见 [劳力士表带专章](/brands/rolex/bracelets) |

### 操作逻辑要点

- **表冠单档调时**：逆时针旋松 Triplock 表冠后，0 档可直接手动补链；本款无日历功能，**拉出仅有 1 档**（停秒调校时间），调毕须顺时针按压旋紧。
- **计时按把“先松再按、停后再归零”**：使用 2 点（启动/暂停）与 4 点（归零）按钮前，**务必先逆时针旋松滚花锁紧螺帽**；计时运行期间**严禁直接强按 4 点归零**，必须先按 2 点停止计时再按 4 点归零（原理详见 [计时功能专题](/general/functions/complications/chronograph)）。日常佩戴与下水前须旋紧两枚按钮螺帽。

## 四、本款特殊之处深度详解

1. **一体式表耳不可改全金链带**：很多新手误以为买一只胶带 `116515LN` 日后花钱配一条全玫瑰金蚝式带即可“一表两戴”。实际上，由于 `116515LN` 表壳两耳之间多了一块**一体铸造的 18K 金固定端头肩位**，结构上**完全无法安装常规全金蚝式链带**，购表前必须明确这一硬性物理限制（详见 [劳力士型号解读](/brands/rolex/reference-guide)）。
2. **永恒玫瑰金的抗褪色壁垒**：传统含铜玫瑰金长期接触汗液与泳池氯水容易发黄发白，而劳力士自 2005 年起在 `Au750` 配方中加入微量铂金原子锁色，使 `116515LN` 经历多年佩戴依然保持温润红润的粉金色泽。
3. **陨石盘的“孤品属性”**：每一片天然铁陨石的魏德曼晶体纹理走势、明暗反光角度都不相同，因此每一块 `116515LN-0055` 实质上都是“一表一纹”的天然孤品。

## 五、二手收售核验与行情逻辑

::: warning 收表生死红线：严防普通盘面后换“高仿/组装陨石盘”
2020 年新版深绿 NFC 保卡**绝不打印 `-0055` 或 `-0059` 盘面尾码**。由于 `116515LN-0055` 陨石盘与常规黑盘、粉盘在二手市场上存在十数万元级的巨大价差，收表时务必核验**白色条码吊牌（White Tag）**；无白吊牌的陨石盘必须用高倍寸镜查验**魏德曼花纹在各角度下的立体金属晶体衍射反光**（印刷或激光雕刻仿陨石盘反光死板无晶界立体感）及劳力士官方盘面印刷字体锐度。
:::

1. **Oysterflex 胶带 `C–H` 固定尺码段与缓冲鳍**：Oysterflex 内部包裹钛镍合金片，**严禁像普通橡胶带一样用剪刀裁剪**，只能通过更换对应尺码段（`C / D / E / F / G / H`）调节。收售时需翻看胶带背面模压字母确认尺码是否适合买家手腕，并检查贴腕侧标志性的**纵向弹性缓冲鳍**是否完整、有无开裂或老化硬化（单根原厂胶带更换成本较高）。
2. **外露陶瓷圈微崩口与旋入按把检查**：老款无金属包边护圈，需用 10 倍镜绕圈排查黑陶外沿微小崩边；同时测试 2 点、4 点计时按钮螺帽螺纹是否顺滑、有无滑丝卡顿。
3. **18K 玫瑰金扣面与表壳成色**：Oysterlock 折叠扣表面面积较大且为拉丝/抛光拼接，极易产生桌面划痕；重点检查表耳正面原厂拉丝纹路及表扣小皇冠立体度，避免购入经过过度打磨、棱角塌陷的翻新表。
