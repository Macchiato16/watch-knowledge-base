## 一、三步视觉漏斗口诀（3 秒锁定劳力士 24 款型号）

::: tip 新人实战口诀：先定外圈 → 再看窗针 → 最后查表带与包边断代
1. **第一步：看外圈结构与刻度形态（一刀切出七大阵营）**
   - **测速计外圈（带 `UNITS PER HOUR` 与 `400..60` 刻度）**：全系锁定**宇宙计型迪通拿**！其中**黑色或栗棕色陶瓷测速圈**覆盖钢迪（`116500LN / 126500LN`）、Oysterflex 胶带金迪（`116515LN / 116518LN / 126518LN`）与 950 铂金冰蓝迪（`126506`）；**18K 贵金属直接镌刻测速圈**覆盖全金链带迪（`116505 / 116508 / 126505 / 126508`）；**36 颗梯方渐变蓝宝石彩虹圈 + 表耳圆钻**锁定原厂彩虹迪（`116595RBOW / 126599RBOW`）。
   - **18K 金三角坑纹“狗牙圈”（无数字刻度）**：锁定正装双杰——**星期日历型**（`128238 / 228238`）与**日志型**（`126334`）。
   - **三大专业旋转运动外圈（2 秒区分水鬼、GMT 与游艇）**：
     - **单向 60 分钟亮面凹刻陶圈 + 12 点凸起夜光珠** = **潜航者型**（`126610LN` 黑水鬼 / `126610LV` 星巴克）；
     - **双向 24 小时双色亮面凹刻陶圈（`2..22` 偶数，无夜光珠）** = **格林尼治型 II**（`126710 / 126711 / 126715 / 126720`）；
     - **双向哑光喷砂黑陶底 + 立体凸起镜面抛光浮雕数字** = **游艇名仕型**（`126655`）。
2. **第二步：看盘面窗口、第四根针与表冠方向，细分跨系与异形款**
   - **狗牙圈阵营内**：12 点位有**弧形全拼星期窗**（如 `MONDAY`）= **星期日历型 DD**（100% 纯贵金属）；无 12 点星期窗 = **日志型 `126334`**（白色黄金钢）。
   - **格林尼治 II 六款内**：**表冠与日历窗在左侧 9 点位** = 绿黑雪碧圈 **`126720VTNR`**；表冠在右侧看双色圈与针色——红蓝红针 = 百事 **`126710BLRO`**，蓝黑蓝针 = 国米 **`126710BLNR`**，灰黑绿针绿字 = 皮蛋 **`126710GRNR`**，棕黑沙士圈看表耳是银白钢（间金 **`126711CHNR`**）还是全玫瑰金（全金 **`126715CHNR`**）。
3. **第三步：看“陶瓷圈金属包边 + 6 点小皇冠 + 透底”，精准断代防错价**
   - **迪通拿 `1165xx` 老代 vs `1265xx` 新代生死线**：老代陶瓷圈为**一体全外露无金属包边**、三眼子盘环较粗、**6 点位 `SWISS MADE` 中间无小皇冠**（`Cal. 4130`）；2023 换代 `1265xx` 陶瓷圈外缘新增**一圈同材质金属外框包边**、子盘环与条钉收窄、**6 点位印有 `SWISS [小皇冠] MADE`**（`Cal. 4131`，且胶带款升级 **Glidelock** 微调扣、950 铂金 `126506` 独占**蓝宝石透底**）。
   - **DD 36mm vs 40mm**：`128238`（36mm）钻刻多为“8 圆钻 + 6/9 梯钻”；`228238`（40mm）冰糖钻全系为 **10 颗全长阶梯方钻**，且多数带微缩罗马字分钟外轨。
:::
