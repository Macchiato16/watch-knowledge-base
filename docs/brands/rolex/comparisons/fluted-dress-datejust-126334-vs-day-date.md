# 狗牙圈正装表跨系防混：日志型 126334 vs 星期日历型 128238 / 228238

## 一、为什么把这几款放在一起比？

在劳力士正装休闲阵营中，**日志型 41（Datejust，代表型号 `126334`）** 与 **星期日历型（Day-Date，代表型号 `128238` / `228238`）** 是全系最容易让纯新人看走眼的一对“跨系双胞胎”：

- **正面主视觉高度相似**：两者均配备劳力士标志性的 **18K 贵金属三角坑纹外圈（狗牙圈）**、**中央大三针**以及 **3 点位 2.5 倍 Cyclops 小窗凸透镜日历（水泡眼）**。
- **缩略图下极易错判十万级与三十万级**：尤其在客户发来模糊微信缩略图、或对比白金款 Day-Date 与白金钢 Datejust `126334` 时，新人极易把“十万级精钢白金圈日志型”误认为“三十万级全贵金属元首表”（或把贵金属 DD 当成普通日志报价），直接造成致命错价！必须牢记三秒跨系切分铁律。

## 二、核心差异对照表

| 对比维度 | 日志型 41（Ref. 126334） | 星期日历型（Ref. 128238 / 228238） |
| --- | --- | --- |
| **12 点位盘面结构** | **无星期窗**（仅 12 点立体皇冠 Logo + `ROLEX` 字样） | **12 点位弧形全拼星期大窗**（如 `MONDAY`，支持 26 种语言） |
| **日历与机芯代号** | 3 点单日历，搭载 **`Cal. 3235`**（约 `70` 小时动储） | 12 点星期 + 3 点日历双历瞬跳，搭载 **`Cal. 3255`**（约 `70` 小时动储） |
| **表带标配形态** | **五排细密纪念型表带（五珠带）** 或 **三格蚝式板带** | **三排半圆柱形元首型表带（总统带 / President）** |
| **表扣结构差异** | **长方形蚝式折扣（Oysterclasp）**，内藏 `5 mm` Easylink 易调链节 | **隐形皇冠折叠扣（Crownclasp）**，闭合后仅见立体小皇冠、无长方扣盖 |
| **材质绝对铁律** | 尾码 **`4` = 白色黄金钢**（904L 蚝式钢壳带 + **仅 18K 白金狗牙圈**） | **100% 纯 18K 金或 950 铂金**，**历史上绝无任何精钢或间金款** |
| **表冠防水与印记** | Twinlock 双扣锁，钢表冠皇冠下为**一横杠** | Twinlock 双扣锁，18K 金表冠皇冠下为**双圆点 `••`** |
| **二手核心红线** | 防光圈 `126300` 后改假狗牙圈、黑/银盘改假薄荷绿/假绿萝盘 | 防低价盘换高价绿/矿石盘、重金克重缺节、狗牙圈抛秃 |

## 三、实战看图一秒切分法

### 第一眼：看 12 点位有没有“弧形全拼星期窗”——直接定生死

- **12 点位正上方有弧形扇面大窗，完整拼写英文或其他语言星期全称（如 `MONDAY`）**：**100% 是星期日历型（Day-Date）**。
- **12 点位没有任何窗口，只有一枚立体小皇冠 Logo**，全盘仅 3 点位一个水泡眼日历：**100% 是日志型（Datejust）**。

*图：星期日历型 Ref. 228238-0069 实拍。12 点位独有弧形全拼星期大窗（`MONDAY`），搭配三排半圆柱形元首型表带（总统带）与全 18K 黄金壳带，贵金属体量与社交层级完全不同。*

### 第二眼：看“表带节数排列 + 表扣形态”——防混与鉴真

即使只看到表侧或腕背照片，通过表带与表扣也能一秒切分：

- **元首带（3 排半圆弧形实心金节）+ 隐形皇冠折叠扣（Crownclasp，闭合后链节无缝衔接、仅见立体小皇冠开启拨杆）**：**Day-Date 专属**。
- **五珠带（5 排细密小链节）或三格板带 + 长方形蚝式折扣（Oysterclasp，带 `5 mm` Easylink 易调链节）**：现代 **`126334` 日志型标配**（注：老款 5 位数/早期 6 位数日志五珠带曾配隐形皇冠扣，但现役 `126334` 已全面改为长方形蚝式折扣）。

![劳力士日志型 41 Ref. 126334-0022 温布尔登绿萝盘](/images/brands/rolex/dj-sub-ym/m126334-0022.jpg)

*图：日志型 Ref. 126334-0022（温布尔登绿萝盘）实拍。同样没有 12 点星期窗，9 点位保留单根白色夜光条钉平衡 3 点水泡眼日历，配五珠带与蚝式折扣。*

### 第三眼：牢记“材质绝对铁律”——一眼踢出拼装假表

- **Day-Date 材质绝对铁律**：自 1956 年诞生至今，星期日历型 **100% 只使用纯 18K 金（黄金 / 白金 / 永恒玫瑰金）或 950 铂金制造，历史上从未出过任何精钢或间金款**！如果在市场上看到“钢色质感极轻的 DD”或“五珠带 DD”，直接判定为假表或拼装表！
- **`126334` 白色黄金钢防错**：型号尾码 **`4`** 代表白色黄金钢（White Rolesor）——整表壳、底盖、表冠与五珠/板带全部为 **904L 蚝式钢**，全表**只有那一圈三角坑纹狗牙圈是 18K 白金**，切勿误报为“全白金表”。

::: danger 收表红线：日志防“光圈改狗牙/换假绿盘”，DD 防“克重抛秃/缺节”！
1. **`126334` 两大改装重灾区**：
   - **光圈 `126300` 换装副厂假狗牙圈**：两者同壳同机芯，极易拆换外圈套利。原装 18K 白金狗牙圈呈冷冽暖白金光泽、钻石刀铣削棱角如刀锋；副厂钢圈颜色发乌且棱线钝软。
   - **普通黑/银盘拆换假薄荷绿（`-0028`）/ 假绿萝（`-0022`）盘**：2020 年后深绿 NFC 保卡只印 `126334` 不印尾码，务必核对 **White Tag 白吊牌**及放大镜下 6 点小皇冠、`SWISS MADE` 油墨锐度（绿萝盘 9 点位必须为单根夜光条钉）。
2. **Day-Date 重金克重与翻新红线**：DD 整表为纯 18K 金，收售必核 **18K 金狗牙圈棱角是否被“抛秃变太阳圈”**、元首带节数是否齐全（缺一节补配成本数千元），以及隐形皇冠扣拨杆有无过度打磨变形。
:::
