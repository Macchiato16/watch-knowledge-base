# Ref. 7118 — 自动机械主力女款鹦鹉螺（35.2 mm）

**Ref. 7118** 于 2015 年正式推出（全面接替并升级自早期 `33.6 mm` 的 `Ref. 7018`），是目前百达翡丽 Nautilus（鹦鹉螺）女装系列中流通量最大、市场认可度最高的**绝对主力自动机械表款**。其对角线表径扩大至契合现代审美的 **`35.2 mm`**，全系标配**蓝宝石水晶背透**，在保留鹦鹉螺标志性八角舷窗轮廓的同时，注入了更柔美灵动的女性化盘面细节。

## 二、三大梯度主流配置变种

在日常收售与报价中，`7118` 家族按表圈镶嵌规格清晰划分为**素圈一体链带款**、**`/1200` 原厂圆钻圈链带款**与**满钻高级珠宝款**三大价格梯度：

### 1. 素圈一体链带款（二级市场超级硬通货）
- **`7118/1A`（精钢素圈）**：二级市场热度最高、流通性极强的“女表钢王”。常见盘面包括 **`7118/1A-001`（经典蓝灰渐变盘）**、**`7118/1A-010`（银白乳光盘）** 与 **`7118/1A-011`（烟熏灰盘）**。
- **`7118/1R`（全 18K 玫瑰金素圈）**：全金份量十足且不带钻的干练风格，代表型号为 **`7118/1R-001`（银白乳光盘）** 与 **`7118/1R-010`（黄金香槟色调渐变盘）**。

### 2. 原厂圆钻表圈链带款（`/1200` 叠加编码）
根据[百达翡丽型号解读](/brands/patek-philippe/reference-guide)的编码规则，**`/1200` = `/1`（金属链带）+ `200`（原厂明亮式圆钻）**。该梯度在八角形表圈上原厂镶嵌 **56 颗顶级威塞尔顿明亮式切割圆钻**（约 0.67 克拉）：
- **`7118/1200A`（精钢圆钻圈）**：包含 `-001` 蓝盘、`-010` 银白盘、`-011` 烟熏灰盘等；
- **`7118/1200R`（全 18K 玫瑰金圆钻圈）**：如 `-001` 银白盘、`-010` 黄金香槟盘，兼顾贵金属质感与华丽钻圈火彩，是高端女性客群点名率极高的配置。

### 3. 满钻高级珠宝款（Haute Joaillerie）
- **雪花镶嵌满钻款**：如 **`7118/1450R`**（玫瑰金）、**`7118/1450G`**（白金），表壳、表圈、表盘与一体式链带大面积采用不规则“雪花镶嵌（Snow-setting）”工艺铺满数千颗尺寸各异的圆钻；
- **彩色宝石高珠款**：如 **`7118/1451G`**（蓝宝石）、**`7118/1452G`**（红宝石）、**`7118/1453G`**（祖母绿）等白金满钻配彩色宝石梯形时标高珠版本，多按珍稀配额供应。

## 三、二手防坑重中之重：严查 `/1200` 防“素圈后镶钻”

::: danger 业务红线：素圈 `7118/1A` 改钻冒充 `7118/1200A`
由于原厂素圈 `7118/1A` 与原厂圆钻圈 `7118/1200A`（以及 `7118/1R` 与 `7118/1200R`）在**公价与二级市场行情上存在巨大的价差**，坊间极常出现不法商贩收购素圈 `7118/1A`，在表圈上**第三方后镶 56 颗圆钻**后冒充原厂 `7118/1200A` 高价出售！

**收售验表四步铁律**：
1. **死磕出生纸编码**：原厂钻圈的出生纸与保卡上**必须明确印有 `/1200`**（如 `7118/1200A-001`）；若证书只写 `7118/1A-001` 或 `7118/1R-010`，而实物带钻圈，**100% 为后镶钻**！
2. **核查表圈厚度与镶口**：素圈表圈厚度与原厂钻圈表圈坯料存在细微结构差异，后镶钻常需在原素圈上直接挖槽，导致表圈边缘金属变薄、棱线坍塌。
3. **检验镶工与钻石一致性**：百达翡丽原厂起钉镶（详见[百达翡丽品牌工艺](/brands/patek-philippe/craftsmanship)）的金属小爪圆润饱满、每颗钻石台面高度与火彩完全一致；后镶钻常见爪型尖锐不均、钻石净度参差不齐。
4. **区分机芯代际**：`7118` 早期为 `Cal. 324 S C`（拔出表冠时秒针不停），2019 年前后逐步换装支持停秒与优化上链离合结构的 **`Cal. 26-330 S C`**，报价与建档时需核对机芯刻字。
:::
