# 百达翡丽 Aquanaut Luce Ref. 5069（35.6 mm 18K 白金自动机械钻圈女款手雷）

**Ref. 5069（`5069G`）** 与玫瑰金 [`5068R`](./5068.md) 同属百达翡丽第一代 **35.6 mm** 自动机械女装 Aquanaut Luce 家族的“贵金属双姝”（均已停产）。与玫瑰金的张扬暖润不同，`5069G` 采用冷冽内敛的 **18K 白金（`G`）** 打造表壳与表扣，搭配原厂镶嵌明亮式切割圆钻表圈（部分常规与高珠版本更延伸至表耳正面、表冠护肩与表冠镶钻），内部搭载带 21K 黄金自动陀的 **`Cal. 324 S C`** 自动上链机械机芯并配**蓝宝石水晶透底**。

在二手收售实务中，**`5069G` 是整个 35.6 mm 女款手雷系列里最需要“一眼防错价”的高危型号**——因为从正面照片看，它与入门精钢石英款 [`5067A`](./5067.md) 同样呈现“银白色金属表壳 + 钻圈 + 黑/白手雷胶带”，但两者的材质成本、机芯级别与二级市场估值完全不在同一个维度。

## 一、一眼特征盘点（视觉识别锚点）

收到“银白色表壳 + 钻圈 + 黑/白胶带”的 35.6 mm 手雷询价时，先按以下四项锚点快速定真身：

| 识别维度 | `5069G` 核心视觉锚点 | 易混型号对比关键差异 |
| --- | --- | --- |
| **① 表径代际与表耳衔接** | **35.6 mm** 18K 白金表壳，**传统外露生耳结构**（胶带平头衔接不包覆表耳外侧），整表带有**沉重 18K 白金压手感** | 与 [`5067A`](./5067.md) 壳型尺寸相同，但精钢壳轻盈得多且无贵金属压手感 |
| **② 表圈钻数与高配珠宝细节** | 表圈原厂 **46 颗**圆钻；常见**表耳正面、表冠护肩同步原厂密镶圆钻 + 表冠镶钻**的奢华细节；**3 点位日历窗左侧保留完整立体白金数字 `3`** | [`5067A`](./5067.md) 表耳/护肩无原厂镶钻版本，且 3 点位日历窗旁**无数字 `3`**（仅窗右侧有一短夜光条标） |
| **③ 底盖与秒针走法** | **蓝宝石水晶透底盖**，可见 `Cal. 324 S C` 机芯与 **21K 黄金大摆陀**；**中央大秒针连续顺滑扫秒** | [`5067A`](./5067.md) 为**实心精钢密底 + 石英秒针一秒一跳** |
| **④ 一秒防错价锚点** | 正面小图看两点：**① 3 点位有数字 `3`；② 表耳/护肩是否带钻**；实物/视频看背面：**背透金陀 + `Au750` 印记** | 绝不可将 `5069G` 误报为 `5067A` 精钢石英价，亦防拿 `5067A` 冒充白金机械款报价 |

## 二、功能盘点与操作逻辑

### 1. 核心规格参数总览

| 项目 | 官方规格与核心特征 |
| --- | --- |
| **系列与定位** | Aquanaut Luce 第一代经典 18K 白金自动机械女款（**已停产**） |
| **家族分工定位** | 35.6 mm 三剑客中的**低调白金机械旗舰**（对比 [`5067A`](./5067.md) 精钢石英、[`5068R`](./5068.md) 玫瑰金机械） |
| **表壳材质与尺寸** | **18K 白金（`G`）**，表径约 **35.6 mm**，旋入式白金表冠（部分版本表冠镶钻） |
| **防水深度** | **120 米**（12 ATM） |
| **宝石镶嵌** | 表圈原厂镶嵌 **46 颗明亮式切割圆钻**（约 1.0 克拉；`5069G-001` 等常见表耳正面、护肩与表冠同步镶钻，另有极少数满钻盘面高珠延伸版） |
| **底盖结构** | **蓝宝石水晶透底盖** |
| **搭载机芯** | **`Cal. 324 S C`** 自动上链机械机芯（21K 黄金中央自动陀、连续扫秒、**拔冠不停秒**） |
| **表带与表扣** | Tropical 复合材料橡胶表带，配 **18K 白金** 双按折叠扣 |

### 2. 显示功能与表冠档位操作逻辑

- **显示功能**：中央时、分针 + **中央机械扫秒大秒针** + **3 点位日历视窗**。
- **表冠三档操作逻辑（旋入式表冠，`Cal. 324 S C` 不停秒特性）**：
  1. **0 档（解锁与手动补链）**：逆时针旋松表冠弹出至 0 档，顺时针旋转可为发条盒手动上链（停走后建议手动补链 20–30 圈）。
  2. **1 档（中间档 · 快调日历）**：轻轻拔出一格快调 3 点位日历，**注意避开晚上 20:00 至凌晨 03:00 的日历切换禁区**，防止损伤拨历齿轮。
  3. **2 档（最外档 · 调时［不停秒］）**：拔至最外档旋转调校时分。因 `Cal. 324 S C` **不支持拔冠停秒**，调时过程中秒针保持走动属正常结构；调校完毕后推回并旋紧表冠以确保防水。

## 四、本款特殊之处深度详解

### 1. 微信小图防错价四重锚点：`5069G` vs `5067A` 终极对照
由于 `5069G`（18K 白金机械）与 [`5067A`](./5067.md)（精钢石英）正面同为“银白色外壳 + 35.6 mm 尺寸 + 钻圈 + 黑/白胶带”，新人极易在微信压缩小图下看走眼。收售报价前必须逐一核验以下**四重锚点**：

1. **第一重（正面盘面速判 · 3 点位数字 `3`）**：`5069G` 因搭载大直径 `Cal. 324 S C` 机械机芯，日历窗更靠外缘，**日历窗左侧保留了完整的立体白金数字 `3`**；而 [`5067A`](./5067.md) 日历窗旁**没有数字 `3`**，仅在窗右侧有一短夜光条标。
2. **第二重（高配珠宝延伸细节）**：许多 `5069G`（如实拍 `5069G-001`）在**表耳正面、表冠护肩甚至表冠顶端**同步原厂密镶圆钻，视觉璀璨度远超仅表圈镶钻的 `5067A`。
3. **第三重（背面底盖与走秒方式）**：`5069G` 为**蓝宝石水晶背透**（可直视 21K 黄金大自动陀）且秒针为**连续扫秒**；`5067A` 为**实心精钢密底**且秒针**一秒一跳**。
4. **第四重（`Au750` 印记与整表克重）**：`5069G` 采用 18K 白金表壳与 18K 白金折叠扣，**整表上手沉甸压手**，表耳背面及表扣内侧必有清晰的 **`Au750`** 与瑞士圣伯纳狗头贵金属印记；`5067A` 则轻盈得多且无贵金属印记。

::: warning 报价风控提示
线上收到“银白色表壳 + 钻圈 + 黑/白胶带”的 35.6 mm 女款手雷询价时，**务必先让客户拍一张背面底盖图和表耳/表扣内侧印记图**，确认究竟是密底精钢石英 `5067A`，还是背透 18K 白金自动机械 `5069G`，再行给出正式收购或销售报价。
:::

## 五、二手收售核验与行情逻辑

实务验表与收售细节补充如下：
1. **表耳与护肩原厂镶钻核验**：遇到表耳、护肩或盘面带钻的 `5069G`，收表时务必结合原厂出生纸（Certificate of Origin）或档案（Extract from the Archives）核实镶嵌规格确系原厂出厂配置，排除第三方后期加镶。
2. **18K 白金镀铑层与棱线检查**：18K 白金表壳表面通常带有镀铑层以保持冷白光泽，若过度抛光翻新容易露出略微偏暖的 18K 白金原色底色，验表时需留意表耳倒角与棱线锐度。
3. **机芯走时与胶带长度**：`Cal. 324 S C` 需上机检测日差（PP 印记成表标准 `-3 / +2` 秒/日）及摆幅；同时核查 Tropical 橡胶带剩余格数，过短需在报价中计入向百达翡丽订购原厂新胶带的成本。
