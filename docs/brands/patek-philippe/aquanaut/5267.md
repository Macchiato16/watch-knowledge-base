# 百达翡丽 Aquanaut Luce Ref. 5267（现代 38.8mm 精钢圆钻石英主力款）

**Ref. 5267/200A** 是百达翡丽于 **2021 年**推出的新一代现代女装“手雷”（Aquanaut Luce）核心主力型号，正式接替服役多年的老款 `5067A`。这一代产品完成了里程碑式的全面换代：表径由 35.6 mm 大幅跃升至大气现代的 **`38.8 mm`**（兼顾女性时尚佩戴与纤细手腕男性玩家），表耳与复合材料橡胶表带改为顺滑贴合的一体式阶梯过渡设计，并换装带四枚独立锁扣的新一代折叠扣，成为现役入门级女装豪华运动表的绝对顶流。

::: tip 现代 Aquanaut Luce 38.8mm 三剑客分工
2021 年换代后，38.8mm 现代女款手雷形成清晰的三线矩阵：
- **`5267`**：**精钢 + 圆钻圈 + 石英机芯**（`Cal. E 23-250 S C`），负责入门走量与潮流配色；
- **`5268`**：**贵金属 + 自动机械背透机芯**（`Cal. 26-330 S C`），并向上延伸至高复杂/高级珠宝系列；
- **`5269`**：**玫瑰金 + 无侧键表冠快调 Travel Time 双时区石英**（`Cal. E 23-250 S FUS 24H`），专攻跨时区出行。
:::

## 三、二手收售与验表：与老款 `5067A` 的四大快速鉴别点

在同行报价与客户现场看表时，务必第一时间区分老款 `5067A`（35.6 mm）与新款 `5267/200A`（38.8 mm），两者在二级市场存在显著价差：

1. **表径直观对比**：新款 `5267/200A` 为 **`38.8 mm`**，老款 `5067A` 为 `35.6 mm`；上手体量感与表盘“手雷”棋盘格格子疏密有明显区别。
2. **表圈钻石颗数**：新款 `5267/200A` 表圈原厂镶嵌 **48 颗**明亮式切割圆钻；老款 `5067A` 为 **46 颗**。快速数圈口钻石颗数是现场核对新老世代的硬指标。
3. **表耳与表带衔接结构**：老款 `5067A` 表耳端与表带之间呈传统内收阶梯段差；新款 `5267/200A` 改为**一体式阶梯顺滑延伸**，表带从表壳直接顺畅延展，且表扣升级为带**四枚独立锁扣**的新一代折叠扣。
4. **型号与出生纸编码规范**：老款常简记为 `5067A-001` 等（无 `/200`）；新款正式规范加入 **`/200`** 圆钻附加码，**核对原产地证书（出生纸）或保卡时必含 `5267/200A`**，且尾码 `-001` / `-010` / `-011` 必须与盘面及胶带原厂配色严格一致。

::: warning 验表提示：橡胶带剪裁余量与“后改色”排查
Aquanaut 系列橡胶表带需按买家腕围剪裁后才能佩戴。收购二手 `5267/200A` 时，务必实测**表带剩余格数（腕围适配度）**——若原装卡其绿（`-011`）或白胶带被剪得过短，替换一条原厂全新胶带不仅成本高，且订货周期较长；同时需核对出生纸尾码，防止有人用 `-001` 黑盘改装或更换 `-011` 绿带绿盘冒充高溢价卡其绿。
:::
