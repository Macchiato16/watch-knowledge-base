# 百达翡丽 Aquanaut Ref. 5167（经典 40.8 mm 大三针 · 现代手雷基石）

**Ref. 5167** 是百达翡丽现代 Aquanaut（手雷）系列的绝对基石。它于 **2007 年**（Aquanaut 系列诞生 10 周年）正式发布，接替初代 `5065`（38 mm）与 `5066`（36 mm），以更现代的 **`40.8 mm`** 表径、极致纤薄的 **`8.1 mm`** 厚度以及与表耳无缝贴合的 **Tropical 复合材料橡胶表带**，将“豪华运动胶带表”推向全球年轻藏家的视野中心。

::: tip 核心定位与在产现状
- **系列定位**：百达翡丽男款豪华运动表的入门级核心主力，兼顾正装衬衫袖口的纤薄贴手度与 `120 米` 防水的日常运动属性。
- **在产状态**：精钢胶带款 **`5167A-001`** 与 18K 玫瑰金款 **`5167R-001`** 目前仍属**核心现役常青款**；精钢一体式金属链带款 **`5167/1A-001`** 市场流通量显著少于胶带款，近年已逐步淡出常规配额视野。
:::

## 一、一眼特征盘点（视觉识别锚点）

- **① 表壳尺寸 / 厚度 / 侧键**：10 点至 4 点对角线表径 **`40.8 mm`**，整表厚度仅 **`8.1 mm`**（极度纤薄）。圆润八角形表圈采用正面垂直缎面拉丝、侧面与倒角镜面抛光工艺（参见 [表壳材质与拉丝抛光](/brands/patek-philippe/materials)）。**无 Nautilus 鹦鹉螺的左右护肩“耳朵”**，仅在右侧 3 点位表冠处保留流线型护肩；**表壳左右两侧均无任何计时或快调按钮/针孔**，防水深度 **`120 米`**。
- **② 棋盘格纹盘面 / 指针 / 视窗位置**：黑灰渐变（`5167A`）或巧克力棕（`5167R`）棋盘格纹浮雕表盘（另有地区限量版如渐变蓝盘红刻度 `5167A-014`），配立体夜光阿拉伯数字时标与中央时、分、大秒针。**3 点位设白底黑字矩形日历窗（注意：3 点位无数字 `3`！）**，盘面无任何其他副盘或小窗。
- **③ 底盖机芯与 Tropical 胶带 / 链带表扣**：蓝宝石水晶透底（早期 `Cal. 324 S C` / 2019 年后 `Cal. 26-330 S C`，21K 金中央自动陀）。标配**无缝贴合表耳内侧弧度的 Tropical 复合材料橡胶带**（或极少见的 `/1A` 一体式精钢金属链带），配折叠扣（早期双按蝴蝶扣或新款四独立锁扣专利折叠扣；`5167R` 表耳背面及扣内压印 `Au750` 贵金属印记）。
- **④ 与手雷家族其他型号的“一秒区分锚点”**：
  - **对比 `5168G`**：`5167` 为 `40.8 mm` 精钢黑盘或玫瑰金棕盘，而 `5168G` 为 **`42.2 mm` 大一圈**、仅 18K 白金且为**午夜渐变蓝或卡其绿盘**；
  - **对比 `5164`**：`5167` 表壳左侧光洁无按钮、3 点位是白底黑字日历窗（无数字 `3`）；`5164` 左侧有两枚长条形快调按钮、3 点位恢复完整数字 `3`、6 点位带指针日历圆盘与 `LOCAL`/`HOME` 昼夜窗；
  - **对比 `5968`**：`5167` 右侧无 2/4 点计时按钮、6 点位无八角形计时副盘。

## 二、功能盘点与操作逻辑

- **盘面显示功能**：中央时针、中央分针、中央大秒针 + **3 点位瞬跳日历窗**（白底黑字）。
- **3 点位旋入式表冠三档操作**：
  1. **0 档（旋紧锁死位）**：顺时针拧紧表冠，确保 **`120 米`** 防水密封；
  2. **0 档（逆时针旋开弹起）**：手动上链档，顺时针旋转即可为发条盒补能；
  3. **1 档（向外轻拉一格）**：快调日历档，顺时针旋转快速推进 3 点位日历数字；
  4. **2 档（拉至最外格）**：调校时间档，双向旋转指针校对时分。
- **机芯演进与停秒功能区分**：
  - **早期批次（2007–2019 年）**：搭载 **`Cal. 324 S C`** 自动上链机芯（21K 金自动陀、Gyromax 摆轮、Spiromax 硅游丝、4 Hz 振频、约 35–45 小时动储），**拔出表冠不停秒**；
  - **现役后期批次（约 2019 年起逐步换装）**：升级为 **`Cal. 26-330 S C`** 自动上链机芯，优化了自动上链离合齿轮结构并**新增拔冠停秒功能**（拉至 2 档时秒针立即停止，便于精准对时），符合 [百达翡丽印记（PP 印记）](/brands/patek-philippe/) `-3 / +2` 秒/日精度标准。
- **调校禁区**：**严禁在晚上 20:00 至凌晨 03:00 之间使用 1 档快调日历**！此时日历齿轮正处于换日啮合期，强行快调极易损坏拨历轮齿；如腕表停走，务必先在 2 档将指针拨至安全时段（如 6:00），再退回 1 档快调日历。

## 四、本款特殊之处深度详解与收售实操

### 1. Tropical 胶带“一刀剪短不可逆”与新老两代折叠扣演进
- **胶带剪裁不可逆机制**：区别于常规带孔表带，Aquanaut 原厂 Tropical 橡胶带没有传统调节孔，专柜售出时需根据表主腕围**直接用刀剪短表带两侧格数**再装入折叠扣。一旦前任表主腕围较细、胶带被剪得过短，**物理上无法接长还原**，买家往往需自费数千元向官方售后订购全新原装胶带（且常面临订货周期）。收表时务必实测佩戴周长并清点 12 点/6 点侧剩余格数，过短应在估价中扣除换带成本。
- **新老两代折叠扣核对**：早期 `5167` 配备**老式双按蝴蝶扣（一体式卡扣）**；近年新款已全面升级为**四独立锁扣专利折叠扣**（表扣两侧需同时按压解锁，中间卡拉卓华十字扣盖下方带有四个独立卡爪）。收表时若发现 2020 年后的新表配老式旧扣，或扣内刻字深度与倒角抛光粗糙，需高度警惕拼装或后配扣。

### 2. 罕见原厂钢链款 `5167/1A-001` 与胶带款 `5167A-001` 的编码及配件差异
- **官方编码严格区分**：`5167A-001`（原配胶带）与 `5167/1A-001`（原配钢链）在出生纸/保卡上的型号编码截然不同（是否带有 **`/1`**）。
- **结构与估价红线**：原厂钢链款采用中节镜面抛光、两侧拉丝的三段式一体钢链与专用头粒连接表耳；市场上存在极少数将 `5167A-001` 自行购买原厂或副厂钢链改装的情况，验表时必须核对出生纸编码与表耳连接处原装状态，严禁将后配钢链的改装表按原厂 `5167/1A-001` 溢价收售。

::: warning 二手验表快速核对清单
1. **交叉比对机芯与年份**：结合出生纸年份核对机芯是 `Cal. 324 S C`（不停秒）还是 `Cal. 26-330 S C`（拔冠停秒），并与表扣代际匹配。
2. **核查表圈拉丝与倒角**：`5167` 的正面垂直拉丝与侧面镜面抛光极易在粗暴翻新后变圆润，重点观察八角棱线是否锋利。
3. **清点胶带剩余格数**：确认左右两侧剩余格数是否满足目标买家腕围需求。
:::
