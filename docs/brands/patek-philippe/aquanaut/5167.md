# 百达翡丽 Aquanaut Ref. 5167（经典 40.8 mm 大三针 · 现代手雷基石）

**Ref. 5167** 是百达翡丽现代 Aquanaut（手雷）系列的绝对基石。它于 **2007 年**（Aquanaut 系列诞生 10 周年）正式发布，接替初代 `5065`（38 mm）与 `5066`（36 mm），以更现代的 **`40.8 mm`** 表径、极致纤薄的 **`8.1 mm`** 厚度以及与表耳无缝贴合的 **Tropical 复合材料橡胶表带**，将“豪华运动胶带表”推向全球年轻藏家的视野中心。

::: tip 核心定位与在产现状
- **系列定位**：百达翡丽男款豪华运动表的入门级核心主力，兼顾正装衬衫袖口的纤薄贴手度与 `120 米` 防水的日常运动属性。
- **在产状态**：精钢胶带款 **`5167A-001`** 与 18K 玫瑰金款 **`5167R-001`** 目前仍属**核心现役常青款**；精钢一体式金属链带款 **`5167/1A-001`** 市场流通量显著少于胶带款，近年已逐步淡出常规配额视野。
:::

## 一、壳体、盘面与机芯演进特征

### 1. 壳体与表带工程：从“独立块状”到“弧度无缝贴合”
- **尺寸与比例**：10 点至 4 点对角线表径 **`40.8 mm`**，整表厚度仅 **`8.1 mm`**。圆润八角形表圈采用正面垂直缎面拉丝、侧面与倒角镜面抛光工艺（参见 [表壳材质与拉丝抛光](/brands/patek-philippe/materials)），取消了 Nautilus（鹦鹉螺）标志性的左右护肩“耳朵”，仅在表冠右侧保留流线型护肩。
- **贴合式 Tropical 胶带**：区别于初代 `5065A` 表带与表壳之间留有明显缝隙的早期设计，`5167` 首次让 **Tropical 复合材料橡胶表带**的头部弧度与表耳内侧完全贴合，视觉一体感极强，且具备抗海水腐蚀、抗紫外线老化与防过敏特性。

### 2. 机芯升级：`Cal. 324 S C` → `Cal. 26-330 S C`
- **早期批次（2007–2019 年）**：搭载经典 **`Cal. 324 S C`** 自动上链机芯（21K 金中央自动陀、Gyromax 摆轮、Spiromax 硅游丝、4 Hz 振频、约 35–45 小时动储），**不具备停秒功能**。
- **现役后期批次（约 2019 年起逐步换装）**：升级为全新一代 **`Cal. 26-330 S C`** 自动上链机芯。在维持纤薄厚度与 21K 金摆陀的基础上，新增了**拔出表冠秒针归零停秒功能**，同时优化了自动上链离合齿轮结构，防止指针回跳与上链磨损，并带有 [百达翡丽印记（PP 印记）](/brands/patek-philippe/) 的 `-3 / +2` 秒/日成表走时精度保证。

## 三、二手收售与验表实操要点

::: warning 头号收售痛点：原厂橡胶表带剪裁不可逆！
1. **必须清点胶带两侧剩余格数**：Aquanaut 的原厂 Tropical 橡胶表带没有常规微调孔，专柜售出时需根据表主腕围**直接用刀剪短表带两侧格数**再装入折叠扣。一旦前任表主腕围较细、胶带被剪得过短，**无法接长还原**！买家往往需自费数千元向官方售后订购全新原装胶带（且常面临订货等待期）。收表时务必实测佩戴手腕周长并清点 12 点/6 点侧剩余格数，过短的胶带应在估价时扣除换带成本。
2. **核对折叠扣版本与生产年份**：早期 `5167` 采用老式一体式卡扣（内部刻字与锁紧结构较早期）；近年新款已全面升级为**四独立锁扣专利折叠扣**（表扣两侧需同时按压解锁，中间卡拉卓华十字扣盖带四个独立卡爪）。若 2020 年后的新表却配老式单扣，或表扣刻字深度/抛光边缘粗糙，需高度警惕拼装或后配扣。
3. **机芯与出生纸年份交叉比对**：`Cal. 324 S C` 与 `Cal. 26-330 S C` 在夹板布局与自动陀结构上有明显差异（且后者具备停秒），收表时务必结合出生纸/保卡年份核对机芯版本与表扣代际是否一致。
4. **区分 `5167A-001` 与 `5167/1A-001` 原配状态**：`5167A-001`（胶带款）与 `5167/1A-001`（钢带款）在出生纸上的型号编码截然不同（是否带有 `/1`），严禁将后配原装胶带或副厂钢带的改装表按原厂对应型号估价。
:::
