# 百达翡丽 Aquanaut Ref. 5164（Travel Time 双时区 · 最实用运动两地时）

**Ref. 5164** 于 **2011 年** 首次将百达翡丽独家的 **[Travel Time 双时区](/general/functions/complications/dual-time)** 机械结构引入 Aquanaut 手雷家族。它将实用主义跨时区操作、清晰直觉的昼夜与指针日历显示，融入 `40.8 mm` 运动表壳之中，被公认为高净值差旅藏家“最实用、最抗造的百达翡丽复杂运动表”。

::: tip 核心定位与停产换代动态（业务必知）
- **系列定位**：手雷家族中承上启下的实用复杂功能主力，操作逻辑远胜常规两地时腕表。
- **重大停产换代**：**传奇精钢款 `5164A-001` 已于 2024 年正式停产**！同年百达翡丽推出 **18K 白金蓝灰盘新款 `5164G-001`** 接棒，配合现役 18K 玫瑰金款 `5164R-001`，正式将 `5164` 产品线全面升级为**全贵金属（全金）阵容**。
:::

## 一、Travel Time 双时区精妙机械与盘面布局

### 1. 左侧人体工学双快调按钮
- **极简单手调时**：`5164` 表壳左侧（8 点与 10 点位外侧）设有两枚流线型**加减快调按钮**（上方 `-1h`、下方 `+1h`），完美对称右侧表冠护肩。
- **不干扰走时精度**：跨时区旅行时，每按一次按钮，**实心当地时间时针（Local）即向前或向后独立瞬跳 1 小时**，分针与秒针持续正常运行，完全不会因调时破坏走时精度或导致停机。
- **隐身单时区模式**：不需要使用两地时功能时，只需将**实心当地时间时针**调整至与**镂空家乡时间时针（Home）**完全重叠，两枚指针即可合二为一，盘面瞬间回归简洁大三针视觉。

### 2. 6 点位指针日历与双昼夜视窗
- **日历与本地时间联动**：6 点位设有一枚立体地球经纬纹理的**指针式日历副盘**，其日历指针与当地时间（Local）联动，跨过午夜自动跳转。
- **独立昼夜显示**：日历副盘左右两侧分别设有 **`LOCAL`（当地时间）** 与 **`HOME`（家乡时间）** 两个小巧圆形昼夜视窗——**白色代表白天（6:00–18:00），深蓝色代表夜晚（18:00–6:00）**，彻底杜绝因分不清昼夜而误拨电话的尴尬。

### 3. 壳体尺寸与机芯代际
- **壳体尺寸**：对角线表径保持经典 **`40.8 mm`**，因叠加双时区模组，整表厚度为 **`10.2 mm`**（依然十分贴合袖口）。
- **机芯升级**：早期 `5164A` 与早期 `5164R` 搭载 `Cal. 324 S C FUS` 自动机芯；后期 `5164R` 与 2024 年新款 `5164G-001` 均已升级为带停秒与优化离合结构的 **`Cal. 26-330 S C FUS`** 机芯（[PP 印记](/brands/patek-philippe/) 认证，30 米防水——注意因左侧设有非旋入式快调按钮，防水深度不同于大三针款的 120 米）。

## 三、二手收售与验表实操要点

::: warning 实操核验清单：按钮手感、停产溢价与防水认知
1. **实测左侧双快调按钮**：收表时必须反复按压左侧 8 点与 10 点位按钮，确认**实心当地时间时针向前/向后瞬跳干脆利落、无卡滞、无连带跳格**，且在跨越午夜 12 点时能准确带动 6 点位日历指针同步前进或倒退。
2. **核查 `HOME` / `LOCAL` 昼夜窗同步性**：转动表冠校时时，观察 `LOCAL` 与 `HOME` 圆形视窗是否在 **6:00 与 18:00** 附近准时进行蓝/白切换，确保没有盘面装配错位或齿轮滑齿。
3. **30 米防水意识与表壳密封性**：由于左侧两枚快调按钮结构限制，`5164` 官方防水深度为 **`30 米`**（而非 `5167` 的 120 米）。收表时需检查表壳左侧按钮缝隙是否有水渍腐蚀或氧化痕迹，切勿按水下操作按钮。
4. **胶带格数与表扣**：同样遵循手雷 Tropical 橡胶带**剪裁不可逆**原则，需核点剩余格数及表扣与年份的对应性（新款均配四独立锁扣折叠扣）。
:::
