# 鹦鹉螺极简基础三代对比：5711 vs 5811 vs 5810

## 一、为什么把这三款放在一起比？

在百达翡丽男款 Nautilus（鹦鹉螺）中，**`5711`、`5811` 与 `5810`** 是仅有的三款**圆润八角表壳 + 左右对称护肩耳 + 水平横纹盘面 + 无任何副盘**的极简基础款：

- **前后代与周年脉络一脉相承**：`5711`（2006–2021 年）是统治二手市场 15 年的钢王标杆；`5811/1G-001`（2022 年接棒）是其官方白金正统继任者；`5810/1G-001`（2026 年）则是致敬 1976 年初代 `3700` 双针精神的 50 周年纪念超薄款。
- **照片极其撞脸，价差高达数倍**：三者均采用标志性的日辉蓝水平横纹盘与八角舷窗轮廓，客户发来一张正面远景照时，极易把**仅设 18K 白金的 `5811/1G`** 当成已经停产的精钢 `5711/1A` 错报价，或把**无秒针无日历的 50 周年限量 `5810`** 混为一谈。

## 三、实战看图一秒切分法

### 第一步：先看“盘面有没有秒针和日历”——一秒切出 `5810`

拿到照片第一眼先扫**中央指针与 3 点位**：只要发现**没有大秒针、也没有 3 点位日历窗**，直接 100% 锁定 50 周年限量款 `5810`。翻到背面看透底，偏心 **22K 金珍珠陀**上清晰的 **`"50 1976 – 2026"`** 纪念刻字以及 `6.9 mm` 的极致超薄侧面，是它与 `5711`/`5811` 彻底拉开维度的铁证。

### 第二步：同为蓝盘大三针+3点日历——正面看尺寸与日历框，背面看底盖接缝区分 `5711` 与 `5811`

当盘面同时具备**大三针 + 3 点位日历窗**时，重点防把白金 `5811/1G` 误报成精钢 `5711/1A`：

1. **看背面底盖结构（100% 物理铁证）**：`5711` 为传统三件式表壳，背面蓝宝石视窗外围有一圈清晰的**独立旋入式底盖接缝**；`5811/1G` 采用向初代 `3700` 致敬的**两件式一体底壳**，表背整块白金浑然一体，**完全没有外圈底盖接缝**，且表耳背面带 `Au750` 贵金属印记。
2. **看正面日历框与表扣**：`5811/1G` 标配**18K 白金立体日历窗外框**与盘面外缘渐深黑边，且表扣两侧具备免工具 `2–4 mm` 伸缩微调；`5711` 为 `40 mm` 老式蝴蝶扣，钢款背面无贵金属印记。
