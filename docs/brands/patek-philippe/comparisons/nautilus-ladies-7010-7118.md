# 女款鹦鹉螺双姝对比：32mm 石英钻圈 7010 vs 35.2mm 自动机械 7118

## 一、为什么把这两款放在一起比？

在百达翡丽女款 Nautilus（鹦鹉螺）家族中，**`7010`** 与 **`7118`** 是目前仅有的两款现代主力型号——二者均采用**圆润八角表壳 + 柔美起伏波浪纹盘面 + 12 点位立体阿拉伯数字 `12`**（本篇仅聚焦女款鹦鹉螺双姝，绝不混入棋盘格纹的女款手雷）：

- **正面图极度相似，但“石英 vs 机械”价差巨大**：客户发来一张“波浪纹带钻圈女款鹦鹉螺”照片时，单看正面很容易把 `32 mm` 石英贵金属 **`7010`** 和 `35.2 mm` 自动机械镶钻 **`7118/1200`** 搞混，导致机芯类型、表径与材质估价全盘出错。

## 二、核心差异对照表

| 对比维度 | Ref. 7010（小表径石英钻圈） | Ref. 7118（中号自动机械） |
| --- | --- | --- |
| **日历窗位置（正面铁证）** | **3 点位矩形日历窗**（取代 3 点时标） | **6 点位正下方梯形日历窗**（3 点保留棒状夜光时标） |
| **表径与厚度** | **`32.0 mm`** / `6.9 mm`（极致纤巧） | **`35.2 mm`** / `8.62 mm`（现代中性优雅比例） |
| **表壳材质范围** | **仅 18K 贵金属**（玫瑰金 `R` / 白金 `G`，**无精钢款**） | **精钢 `A` + 玫瑰金 `R` + 白金高珠 `G`** 全材质覆盖 |
| **表圈钻数与编码** | **全系标配 46 颗圆钻**（约 0.73 ct），**编码不带 `/200` 或 `/1200`** | 分**素圈**（如 `7118/1A`）与**钻圈 `/1200`**（**56 颗圆钻**，约 0.67 ct） |
| **机芯与秒针走时** | `Cal. E 23-250 S C` **石英机芯（一秒一跳）** | `Cal. 324 S C` / `26-330 S C` **自动机械（连续扫秒，晚期支持停秒）** |
| **底盖形态** | **实心贵金属密底**（不透底，有贵金属印记） | **蓝宝石水晶背透**（可见 21K 金中央大自动陀） |

## 三、实战看图一秒切分法

### 第一步：正面只看“日历窗在 3 点还是 6 点”——100% 零误差铁证

只要看到波浪纹盘面女款鹦鹉螺，**视线直接从 12 点位数字 `12` 往下或往右扫**：
- **日历窗在 3 点位右侧**：100% 是 `32 mm` 石英钻圈 **`7010`**。
- **日历窗在 6 点位正下方（3 点位是完整夜光棒状时标）**：100% 是 `35.2 mm` 自动机械 **`7118`**。

![百达翡丽 Ref. 7010R-013 32mm 玫瑰金紫盘皮带](/images/brands/patek-philippe/nautilus-ladies/patek-7010r-013-purple.jpg)

*图：Ref. 7010R-013 实拍。32 mm 18K 玫瑰金表壳标配 46 颗圆钻表圈，最核心的正面铁证是日历窗位于 3 点位。*

![百达翡丽 Ref. 7010/1R-013 32mm 玫瑰金紫盘链带](/images/brands/patek-philippe/nautilus-ladies/patek-7010-1r-013-purple-bracelet.jpg)

*图：Ref. 7010/1R-013 一体式玫瑰金链带款实拍。同样保持 3 点位日历窗与 46 颗原厂表圈圆钻配置，背面为实心密底石英结构。*

### 第二步：看表圈是否带钻与背面透底——防把 `7118` 素圈与钻圈混淆

- **`7118` 素圈款（如 `7118/1A`）**：无钻金属拉丝八角表圈 + **6 点日历** + 蓝宝石背透机械机芯，精钢入门门槛最低。
- **`7118/1200` 钻圈款**：同样是 **6 点日历** + 蓝宝石背透机械机芯，表圈原厂镶嵌 **56 颗圆钻**（比 `7010` 多 10 颗），注意核对原厂钻圈棱线饱满度以防后镶钻。

![百达翡丽 Ref. 7118/1A-001 35.2mm 精钢蓝盘素圈](/images/brands/patek-philippe/nautilus-ladies/patek-7118-1a-001-blue.jpg)

*图：Ref. 7118/1A-001 精钢素圈蓝盘实拍。35.2 mm 表壳搭配起伏波浪纹与 6 点位正下方梯形日历窗，背面搭载蓝宝石背透自动机械机芯。*

![百达翡丽 Ref. 7118/1200A-001 35.2mm 精钢 56 钻圈](/images/brands/patek-philippe/nautilus-ladies/patek-7118-1200a-001-diamonds.jpg)

*图：Ref. 7118/1200A-001 精钢镶钻款实拍。虽然同样带有钻圈，但 6 点位日历窗与 56 颗圆钻表圈使其一眼区别于 3 点位日历的 `7010`。*
