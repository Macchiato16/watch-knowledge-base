# Cubitus 方形大三针大小号对比：45mm 大号 5821 vs 40mm 中号 7128

## 一、为什么把这两款放在一起比？

在百达翡丽 2024–2025 年推出的全新 **Cubitus 方形运动系列**中，**`5821`（2024 年首发大号）**与 **`7128`（2025 年新增中号）**是仅有的两款**盘面布局 100% 相同的圆角方形水平横纹大三针 + 3 点位日历腕表**：

- **单看正面局部照片极度撞脸**：两款均采用圆角方形八边宽表圈、左右对称护肩耳、水平浮雕横纹盘面、带白金立体边框的 3 点位日历窗，以及完全相同的 **`Cal. 26-330 S C`** 停秒自动机芯（背面均配 21K 金水平横纹专属摆陀）。
- **表径相差整整 `5 mm`，材质与价格完全错层**：`5821` 对角线达 `45 mm`（主打精钢与钢金间金），而 `7128` 对角线缩至 `40 mm`（**全系仅以全 18K 贵金属打造**）。没有参照物对比照片时，新手极易看走眼报错材质与行情。

## 三、实战看图一秒切分法

### 必杀绝招：不用拿尺子量表径！官方“材质 × 盘面配色” 100% 错位零重叠

由于百达翡丽在产品规划上刻意让 `5821` 与 `7128` 的配色和材质完全错开，实战看图只需一眼确认**“盘面颜色 + 表壳金属色”**：

1. **看到「全钢壳 + 橄榄绿盘」或「钢金间金双色链带 + 复古蓝盘」** → **100% 是 45mm 大号 `5821`**。

![百达翡丽 Cubitus Ref. 5821/1A-001 精钢橄榄绿盘](/images/brands/patek-philippe/cubitus/patek-5821-1a-001-front.jpg)

*图：Cubitus Ref. 5821/1A-001 精钢款实拍。45 mm 对角线圆角方形表壳搭配标志性橄榄绿水平横纹盘，是 `5821` 独有的精钢主力配置。*

![百达翡丽 Cubitus Ref. 5821/1AR-001 钢金间金复古蓝盘](/images/brands/patek-philippe/materials/patek-cubitus-5821-1ar-two-tone.jpg)

*图：Cubitus Ref. 5821/1AR-001 间金款实拍。精钢表壳搭配 18K 玫瑰金表圈与链带中节，配复古蓝盘，同样是 `5821` 的专属双色配置。*

2. **看到「全 18K 白金 + 蓝灰盘」或「全 18K 玫瑰金 + 暖棕盘」** → **100% 是 40mm 中号 `7128`**（尤其注意白金款 `7128/1G` 勿当成精钢 `5821/1A`：表背有 `Au750` 贵金属印记，且盘面为冷调蓝灰而非橄榄绿）。

![百达翡丽 Cubitus Ref. 7128/1G-001 40mm 18K 白金蓝灰盘](/images/brands/patek-philippe/cubitus/patek-7128-1g-001-front.png)

*图：Cubitus Ref. 7128/1G-001 实拍。40 mm 紧凑比例全 18K 白金表壳搭配冷调日辉蓝灰横纹盘，表背带 `Au750` 贵金属印记。*

![百达翡丽 Cubitus Ref. 7128/1R-001 40mm 18K 玫瑰金暖棕盘](/images/brands/patek-philippe/cubitus/patek-7128-1r-001-rose-gold-brown.jpg)

*图：Cubitus Ref. 7128/1R-001 实拍。全 18K 玫瑰金表壳与一体链带搭配渐深暖棕横纹盘，与间金蓝盘的 `5821/1AR` 形成鲜明区隔。*
