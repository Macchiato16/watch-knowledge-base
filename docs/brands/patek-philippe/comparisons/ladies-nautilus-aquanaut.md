# 女款鹦鹉螺与女款手雷八大易混型号防错价终极指南：`7010` vs `7118`、`5067/5068/5069` vs `5267/5268/5269`

在百达翡丽二手收售报价中，**女装运动表是最容易发生“严重错价事故”的重灾区**。原因在于：
1. **石英 vs 自动机械**价差巨大；
2. **精钢（`A`）vs 18K 白金（`G`）**同为银白色外壳，单看正面照片极易把白金机械款当成精钢石英款报低价；
3. **老三代（`5067/5068/5069`）与新三代（`5267/5268/5269`）**外观同为棋盘格钻圈胶带手雷，极易张冠李戴。

以下将这 **8 款高频易混女表** 拆成三组实战对比，帮你彻底堵死报错价漏洞。

---

## 一、第一组：波浪纹女款鹦鹉螺——`7010` vs `7118`

两款女款鹦鹉螺均采用标志性的**起伏波浪纹表盘（非男款笔直横纹）**，区分它们只需记住**「日历窗位置 + 表圈钻石 + 机芯背透」**三项铁律：

| 对比维度 | `7010`（小号石英钻圈） | `7118`（大号自动机械） |
| --- | --- | --- |
| **表壳尺寸** | `32 mm` | `35.2 mm` |
| **日历窗位置** | **3 点位**（核心一眼锚点） | **6 点位**（核心一眼锚点） |
| **表圈规格** | **全系标配 46 颗原厂圆钻**（无素圈） | 分**素圈 `/1`** 与 **56 颗原厂圆钻 `/1200`** |
| **表背与机芯** | **密底石英机芯**（Cal. E23-250 S C，秒针一秒一跳） | **蓝宝石背透自动机械**（Cal. 324/330 S C，秒针连续扫秒） |
| **表带常见形态** | 金属链带 `/1` 或皮带（如 `7010R` / `7010G`） | 主流为一体式金属链带（`/1A`、`/1R`、`/1200A`、`/1200R`） |
| **专章直达** | [7010 专章 →](/brands/patek-philippe/nautilus/7010) | [7118 专章 →](/brands/patek-philippe/nautilus/7118) |

## 二、第二组：女款手雷（Aquanaut Luce）新老两代断代——`5067/5068/5069` vs `5267/5268/5269`

收到棋盘格纹的女款手雷照片，第一步先看**表壳与橡胶表带的衔接处**，一秒断出新老两代：

- **老三代（`5067 / 5068 / 5069`）**：表径 `35.6 mm`，表耳与表带之间为**传统外露生耳结构**（表耳末端与胶带之间可见明显间隙与生耳轮廓），表圈镶嵌 **46 颗圆钻**。
- **新三代（`5267 / 5268 / 5269`）**：表径放大至 `38.8 mm`，改用与男款一致的**一体顺滑包覆胶带**（胶带无缝紧贴表壳弧度，无外露生耳间隙），钻圈升级为 **48 颗圆钻**（`5269R` 另有无钻素圈版）。

## 三、第三组：同代内部「生死防错价」细辨（数字 `3` 与 `HOME` 窗）

断出“老三代”还是“新三代”后，下面这一步直接决定**报价会不会赔钱**——尤其是老三代中**精钢 `5067A` 与白金 `5069G` 均呈银白色**，必须死盯 **3 点位是否保留数字 `3`**！

### 1. 老三代内部对比：`5067A` vs `5068R` vs `5069G`

| 对比维度 | `5067A`（精钢石英） | `5068R`（玫瑰金机械） | `5069G`（白金机械 · 高危防错） |
| --- | --- | --- | --- |
| **3 点位数字 `3`** | **无数字 `3`**（日历窗直接取代 `3`） | **保留数字 `3`**（日历窗在 `3` 右侧外缘） | **保留数字 `3`**（日历窗在 `3` 右侧外缘） |
| **表壳材质** | 精钢（银白色） | 18K 玫瑰金 | **18K 白金（同为银白色！）** |
| **表背与机芯** | **密底石英跳秒** | **背透自动机械扫秒** | **背透自动机械扫秒** |
| **专章直达** | [5067 专章 →](/brands/patek-philippe/aquanaut/5067) | [5068 专章 →](/brands/patek-philippe/aquanaut/5068) | [5069 专章 →](/brands/patek-philippe/aquanaut/5069) |

::: danger 最高危防错价红线：`5067A` vs `5069G`
收到银白色老款女手雷时，**看一眼 3 点钟位置**：
- 如果 3 点日历窗**吃掉了数字 `3`**，才是精钢石英 `5067A`；
- 如果 3 点日历窗左侧**完整保留了阿拉伯数字 `3`**，则是 **18K 白金机械款 `5069G`**（贵金属 + 自动机械），两者二级市场价值悬殊，绝不可混报！
