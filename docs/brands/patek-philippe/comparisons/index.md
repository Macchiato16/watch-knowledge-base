# 看图识表总纲：百达翡丽 24 款运动表三步特征锚点定位法

在二手收售与日常估价实战中，新人最常遇到的痛点不是“背不出机芯编号”，而是**“客户发来一张没有型号、没有保卡的照片，如何在 3–5 秒内准确报出基础型号，绝不把百万级复杂款或贵金属款当成入门钢款错报价”**。

百达翡丽三大现代运动主力系列（**Nautilus 鹦鹉螺**、**Cubitus 方形鹦鹉螺**、**Aquanaut 手雷**）合计 **24 个核心基础型号**，看似盘面繁多、尾码复杂，实则具有极强的**视觉几何规律**。只要掌握下面这套「三步视觉漏斗口诀」，看图就能一秒锁定型号。

---

## 一、三步视觉漏斗口诀（3 秒锁定基础型号）

::: tip 新人实战口诀：先定阵营 → 再看副盘 → 最后断代际
1. **第一步：看壳型、左耳与盘面底纹，分出四大阵营**
   - **圆润八角 + 左右对称“护肩耳朵” + 水平横纹**：**男款鹦鹉螺**（`5711 / 5811 / 5810 / 5712 / 5726 / 5980 / 5990 / 5740`，共 8 款）。
   - **圆润八角 + 左右“耳朵” + 起伏波浪纹**：**女款鹦鹉螺**（`7010 / 7118`，共 2 款）。
   - **圆角方形 + 左右“耳朵” + 水平横纹**：**Cubitus 方形鹦鹉螺**（`5821 / 5822 / 7128`，共 3 款）。
   - **圆润八角 + 无左耳 + 棋盘格纹**：**男女款 Aquanaut 手雷**（男款 5 款 + 女款 6 款，共 11 款）。
2. **第二步：看日历窗位置与副盘几何，锁定功能型号**
   - 无秒针无日历 = `5810`；大三针 6 点日历 = `7118`；
   - 不对称三小盘（圆壳 `5712` / 方壳 `5822`）；对称 12 点双矩形窗 = `5726`；极薄 3/6/9 三圆盘 = `5740`；
   - 仅右侧两计时键 = `5980`（鹦鹉螺）/ `5968`（手雷）；左耳裂开变四键 = `5990`；仅左侧双凸键 = `5164`；12 点正上方扇形月相 = `5261R`；6 点 `HOME` 窗无日历 = `5269`。
3. **第三步：看材质色泽、表耳衔接与数字 `3` 细节，精准断代防错价**
   - **男款大三针断代**：`5711`（40mm 三件式有底盖接缝）vs `5811`（41mm 两件式一体底壳、仅白金）；`5821`（45mm 钢绿/间金蓝）vs `7128`（40mm 白金蓝灰/玫瑰金棕）；`5167`（40.8mm 钢黑/玫瑰金棕）vs `5168G`（42.2mm 白金独占蓝/绿）。
   - **女款手雷断代与材质生死线**：老三代 `5067 / 5068 / 5069`（35.6mm **外露传统生耳**、46 颗钻）vs 新三代 `5267 / 5268 / 5269`（38.8mm **一体顺滑包覆胶带**、48 颗钻或素圈）；老代内部看 **3 点是否保留数字 `3`**（无 `3` 是钢石英 `5067A`，保留 `3` 是玫瑰金 `5068R` 或白金 `5069G`）。
:::
