# 百达翡丽型号解读（Reference Guide）

在百达翡丽的日常收售、电话报价与客户沟通中，一串完整的官方型号（Reference）往往就像腕表的“身份证编码”。看懂它，能帮业务人员在几秒内锁定**表壳材质、原厂是皮带还是金属链带、以及表圈钻石究竟是原厂镶嵌还是第三方后改**；但同时，也必须清楚哪些信息**绝对不能靠型号盲猜**。

::: warning 核心原则：区分「100% 可读」与「必须查证」
现代百达翡丽型号遵循高度严谨的四段式编码规则，但**同一后缀在不同型号之间没有固定颜色映射，且多数联名款与生产年份无法单凭型号直接读出**。严禁靠经验“猜尾码颜色”或“按首位数字硬套复杂程度”。
:::

---

## 一、现代百达翡丽型号的完整语法公式

自 **20 世纪末（约 1980–1990 年代逐步规范）至现产表款**，百达翡丽官方目录与原产地证书（出生纸）上普遍采用标准的**四段式全形态编号**，例如 `5711/1A-010`、`5268/200R-010`、`5711/1300A-001`、`5726A-001`、`5980/1AR-001`：

```text
[基础型号数字] + [/ 结构与镶嵌附加码（可选）] + [表壳材质字母] + [- 三位配置尾码]
    5711       +           /1                  +       A        +      -010
    5711       +         /1300                 +       A        +      -001
    5268       +         /200                  +       R        +      -010
    5726       +       (无斜杠)                +       A        +      -001
    5980       +           /1                  +       AR       +      -001
```

- **正式单据与口头简称的差异**：出生纸、保卡及官方目录均印有**带三位尾码的完整型号**（如 `5711/1A-010`）；而日常同行交流或客户口头询价时，常会简称为 `5711A`、`5205G`、`5726/1A` 等。**报价与开单时，必须核对到斜杠与三位尾码**，否则极易把皮带款当成钢带款、或把蓝盘当成绿盘报出错误价格。

## 二、逐段深度拆解：哪些信息能 100% 靠编码直接读出？

### 第一段：基础型号数字（Base Reference，现代主流为 4 位数字）

基础型号数字代表特定的**「表壳设计造型 + 机芯功能配置」**组合。现代主流为 4 位数字，其**首位数字**在产品线上存在明显的**常见分布倾向**，但**绝非绝对铁律，存在大量历史承袭与跨线例外**：

| 首位数字 | 现代常见定位与主力范围 | 代表型号示例 | 必须牢记的例外与避坑提示 |
| --- | --- | --- | --- |
| **`5xxx`** | 现代男表与中性表绝对主力，横跨正装、运动、实用复杂与大量超级复杂功能 | 运动 `5711` / `5811` / `5167` / `5821` / `5822`；年历 `5205` / `5396`；超复杂 `5270` / `5370` / `5236` / `5303` | `5xxx` 既包含入门大三针，也包含百万级万年历计时与三问陀飞轮，**不能认为 `5` 开头就是基础款** |
| **`6xxx`** | 多见于现代顶级超级复杂旗舰或特殊大表径复杂款 | 双面表王 `6002`、大自鸣 `6300`、苍穹图 `6102` | **经典反例：`6119` Calatrava**（如 `6119G-001`）是手动小三针入门正装！**绝不能以为 `6` 开头就一定是超复杂表王** |
| **`7xxx` / `4xxx`** | 现代女装腕表与女装复杂功能主力（含部分中性小表径） | 女款鹦鹉螺 `7118`、女款飞返/双时区 `7234`、Twenty~4 `4910` / `7300`、中性年历 `4947` | `4947` 等 38 mm 年历虽归入 `4xxx`，男女皆可佩戴；`7300` 为圆形自动机械款而非早期方形石英 `4910` |
| **`3xxx`** | 多见于 20 世纪中后期经典停产老款与古董表款 | 初代鹦鹉螺 `3700`、经典万年历 `3940`、三问陀飞轮 `3939` | 属于早年编号体系，部分经典款亦有复杂功能，需结合年代目录核查 |

![百达翡丽 Calatrava Ref. 6119G-001 实拍](/images/brands/patek-philippe/reference-guide/patek-6119g-001-calatrava.jpg)

*图：百达翡丽 Calatrava Ref. 6119G-001。虽然基础型号以 `6` 开头，但它并非超级复杂功能旗舰，而是搭载手动上链小三针机芯（Cal. 30-255 PS）、配巴黎钉纹（Clous de Paris）表圈的 18K 白金正装皮带腕表。*

### 第二段：斜杠 `/` 与附加结构 / 工艺码（二手收售硬核解码段）

在表壳材质字母之前、基础数字之后，如果出现斜杠 `/`，它是二手验表与电话报价中**含金量最高的一段编码**——因为它能 100% 锁定**出厂表带类型**与**原厂宝石镶嵌规格**：

#### 1. 无斜杠 vs `/1`：一秒分清「非金属表带」与「金属表链」

- **无斜杠（如 `5726A-001`、`5167A-001`、`5270P-014`）**：**100% 可读结论**——原厂出厂标配**非金属表链**（鳄鱼皮带、小牛皮带或复合材料橡胶表带），且表壳无常规宝石镶嵌附加码。
- **`/1`（如 `5711/1A`、`5726/1A-014`、`5270/1R-001`、`5821/1AR-001`）**：**100% 可读结论**——原厂出厂标配**一体式金属表链**（精钢链带、全 18K 金链带或间金链带）。

::: tip 业务实战价值：电话报价防错价
同样是精钢年历鹦鹉螺，`5726A-001`（无斜杠，配黑色鳄鱼皮带）与 `5726/1A-014`（带 `/1`，配一体式精钢链带）在二级市场存在数万元价差；而超级复杂款 `5270R-001`（皮带）与 `5270/1R-001`（全 18K 玫瑰金“水滴”表链）差价更是高达数十万元。先问清型号里有没有 `/1`，就能在第一时间避开重大报价失误。
:::

![百达翡丽 Nautilus Ref. 5726A-001 皮带款](/images/brands/patek-philippe/reference-guide/patek-5726a-001-leather.png)

*图：百达翡丽 Nautilus Ref. 5726A-001（无斜杠）。编码中不含 `/1`，代表原厂出厂标配黑色鳄鱼皮表带（非金属链带），配精钢表壳（`A`）与渐变黑灰盘（`-001`）。*

![百达翡丽 Nautilus Ref. 5726/1A-014 钢带款](/images/brands/patek-philippe/reference-guide/patek-5726-1a-014-bracelet.jpg)

*图：百达翡丽 Nautilus Ref. 5726/1A-014（带 `/1`）。同一 `5726` 壳型加上 `/1` 后，代表原厂标配一体式精钢表链；同时此处的 `-014` 对应渐变蓝盘。*

![百达翡丽 Ref. 5270/1R-001 全玫瑰金链带款](/images/brands/patek-philippe/reference-guide/patek-5270-1r-001-bracelet.jpg)

*图：百达翡丽超级复杂功能 Ref. 5270/1R-001。`/1` 与 `R` 组合，明确指示该表出厂即配备全 18K 玫瑰金一体式五排“水滴”金属表链。*

#### 2. `/200`、`/300`、`/400` 与 `/1xxx` 叠加码：原厂镶嵌与二手防“后镶钻”

百达翡丽用三位数字附加码标注原厂宝石镶嵌大类；若该镶嵌表款同时配备**原厂金属表链（`/1`）**，则将 `1` 叠加到百位之前，形成 **`/1200`、`/1300`、`/1400`** 四位数叠加码：

| 斜杠附加码 | 含义拆解（100% 可读结论） | 典型真实型号 | 视觉特征 |
| --- | --- | --- | --- |
| **`/200`** | 非金属表带 + 原厂镶嵌**明亮式切割圆钻（Brilliant-cut）** | `5268/200R-001` / `5268/200R-010` | 胶带或皮带 + 圆钻表圈 |
| **`/1200`** | `/1`（金属表链）+ `200`（原厂**明亮式圆钻**） | `7118/1200A-001` | 金属链带 + 圆钻表圈 |
| **`/300`** | 非金属表带 + 原厂镶嵌**长阶梯形切割方钻/宝石（Baguette-cut）** | `5271/13P`（早期两位数）或现代 `/300` 系列 | 皮带 + 长方钻表圈 |
| **`/1300`** | `/1`（金属表链）+ `300`（原厂**长阶梯方钻**） | `5711/1300A-001`、`5980/1300R` | 金属链带 + 整圈长方钻 |
| **`/400` / `/1400`** | 多见于满钻高珠表壳与满钻表链（Haute Joaillerie） | 现代 `/1400` 系列（早期曾用 `/10` 如 `5719/10G`） | 表壳、表圈、表盘或链带大面积满镶 |
| **`/50` / `/100`** | 珍稀手工艺（Rare Handcrafts）怀表/腕表专用分类码 | 手工雕花、木片细工镶嵌或微绘珐琅孤品 | 需查珍稀手工艺图录确认具体工艺 |

> **年代演进提示**：早期 **1990–2000 年代**，百达翡丽曾使用 **`/10`、`/11`** 等两位数镶嵌码（如早期满钻鹦鹉螺 `5719/10G`），后逐步规范统一为三位数 `/200`、`/300`、`/400` 体系。

*图：百达翡丽 Aquanaut Luce Ref. 5268/200R-001。斜杠码 `/200` 前没有 `1`，表示原厂配复合材料橡胶表带而非金属表链；`200` 明确对应表圈镶嵌的 48 颗明亮式切割圆钻，`R` 为 18K 玫瑰金表壳。*

![百达翡丽 Nautilus Ref. 5711/1300A-001 方钻款](/images/brands/patek-philippe/reference-guide/patek-5711-1300a-001-baguette.jpg)

*图：百达翡丽 Nautilus Ref. 5711/1300A-001。`/1300` 由 `/1`（一体式精钢链带）与 `300`（原厂 32 颗长阶梯形切割方钻表圈）叠加而成，材质为精钢（`A`），`-001` 在此独立型号下对应橄榄绿日辉纹盘。*

::: danger 二手验表红线：一秒识破第三方“后镶钻”
如果一只百达翡丽实物表圈镶满圆钻或方钻，但原产地证书（出生纸）上印刷的型号却是**无 `/200`、`/300` 等镶嵌码的素圈型号**（例如证书写着 `5711/1R-001` 或 `5711/1A-010`，实物却带钻圈），**100% 属于第三方“后镶钻（Aftermarket）”**！原厂镶钻必定拥有独立编码，绝不会共用素圈型号。
:::

### 第三段：表壳材质字母代码（100% 确定可读）

百达翡丽材质字母源自**法语材质名称首字母**，单字母代表纯一材质，双字母代表双色间金组合，属于型号中最稳定、无例外的可读字段：

| 材质代码 | 法语原词 | 对应表壳（及原厂链带）材质 | 业务备注与代表型号 |
| --- | --- | --- | --- |
| **`A`** | *Acier* | **精钢**（Stainless Steel） | 运动表与入门钢款核心溢价代码，如 `5711/1A`、`5167A` |
| **`J`** | *Or Jaune* | **18K 黄金**（Yellow Gold） | 经典复古贵金属，如 `3919J`、`5270J` |
| **`R`** | *Or Rose* | **18K 玫瑰金**（Rose Gold） | 现代贵金属主力，如 `5711/1R`、`5167R`、`5270/1R` |
| **`G`** | *Or Gris* | **18K 白金**（White Gold） | 隐形贵金属，如 `5811/1G`、`6119G`、`5205G` |
| **`P`** | *Platine* | **950 铂金**（Platinum） | 顶级材质封顶，表耳间 6 点位常镶一颗小钻石，如 `5270P`、`5370P` |
| **`T`** | *Titane* | **钛金属**（Titanium） | 极罕见，多用于 Only Watch 慈善孤品或特殊限量款 |
| **`AR`** | *Acier + Or Rose* | **精钢 + 18K 玫瑰金双色间金** | 如 `5980/1AR-001`、`5821/1AR-001`（2024 Cubitus） |
| **`JA`** | *Or Jaune + Acier* | **18K 黄金 + 精钢早期双色间金** | 多见于早期停产间金款（如早期 `3800/1JA`） |

关于各类贵金属与精钢在百达翡丽表款上的密度手感、印记与翻新差异，可进一步阅读 [百达翡丽品牌材质](/brands/patek-philippe/materials) 专章。

### 第四段：连字符与三位配置尾码（`-001`、`-010`、`-014` 等）

连字符 `-` 后的三位数字，用于区分同一型号、同一材质下的**具体盘面配色、时标材质、表带颜色或迭代版本**。

- **唯一可确认的规则**：在**同一个基础型号 + 材质**内部，每一个尾码唯一对应一种官方配置。
- **严明解码边界（绝对不可跨型号套用！）**：**百达翡丽的三位尾码在跨型号之间没有任何固定的颜色映射规则！** 同一组尾码在不同表款上往往对应完全不同的颜色：
  - **`-014` 对比**：`5711/1A-014` 是**橄榄绿盘**，`5726/1A-014` 是**渐变蓝盘**，而 `5270P-014` 则是**绿漆盘**；
  - **`-001` 对比**：`5711/1300A-001` 是**橄榄绿盘**，`5270P-001` 是**鲑鱼盘**，`5270/1R-001` 是**乌木黑盘**，`5320G-001` 是**奶油漆盘**（而 `5320G-011` 才是**鲑鱼盘**）。

## 四、专章重点汇总表：「编码可直接推断项」vs「必须查资料/核对证书项」

在收售评估、客户咨询与培训考核中，请严格以本表作为判断边界，**绝不将不可编码推断的信息当作型号本身能读出的结论**：

| 判断类别 | 具体项目 | 能否单凭型号确认 | 判定依据与实操说明 |
| --- | --- | --- | --- |
| **✓ 可直接推断** | **基础壳型与功能平台** | **能** | 由第一段基础数字（如 `5711`、`5726`、`5270`）直接锁定所属壳型；但首位数字 `5/6` 不能直接决定是否超复杂（牢记 `6119G` 反例） |
| **✓ 可直接推断** | **表壳及间金材质** | **能** | `A`（精钢）、`J`（黄金）、`R`（玫瑰金）、`G`（白金）、`P`（铂金）、`T`（钛）、`AR` / `JA`（间金）100% 确定 |
| **✓ 可直接推断** | **原厂是否配金属链带** | **能** | 含 `/1` 或 `/1200`、`/1300`、`/1400` 必定为原厂金属链带；无斜杠或 `/200`、`/300` 必定为非金属表带（皮带或胶带） |
| **✓ 可直接推断** | **是否原厂镶钻及主石切割大类** | **能** | `/200`（`/1200`）为圆钻、`/300`（`/1300`）为方钻、`/400` 多为满钻；素圈型号实物带钻即属后镶钻 |
| **⚠ 须查证核对** | **具体盘面颜色** | **不能** | 三位尾码跨型号无固定颜色规律（如 `-014` 既可能是绿盘也可能是蓝盘），必须查官方目录 |
| **⚠ 须查证核对** | **是否为特殊联名款** | **不能一概认定** | **顶级二手干货**：绝大多数早期 Tiffany & Co. 双标盘面在型号上与普通版完全一致（同为 `5711/1A-010`），**唯有 170 周年纪念版 `5711/1A-018` 拥有独立尾码**！不可因尾码普通就否定双标，也不能仅凭型号判断双标真伪 |
| **⚠ 须查证核对** | **具体出厂生产年份** | **不能** | 百达翡丽型号、表壳号与机芯号均无公开年份字母对照表，必须核对原产地证书（出生纸）销售日期或向日内瓦申请后补档案（Extract from the Archives） |
| **⚠ 须查证核对** | **具体机芯口径与防水深度** | **不能** | 同型号可能跨代升级机芯（如 `5711/1A-010` 早期用 Cal. 315/324，后期换装 Cal. 26-330 S C），具体参数与防水深度须查官方目录或开盖/看证书确认 |
