# Ref. 5821 — Cubitus 方形运动系列大三针首发主力（俗称“方形鹦鹉螺”，45 mm）

**Ref. 5821** 是百达翡丽于 2024 年 10 月推出的全新 **Cubitus（方形运动系列）**——国内二级市场及藏家圈层俗称 **“方形鹦鹉螺”**——的首发大三针主力表款。之所以得名“方形鹦鹉螺”，是因为该系列虽然将表壳轮廓改为大胆的圆角方形，却原汁原味地延续了 Nautilus（鹦鹉螺）**壳体两侧铰链式护肩耳、水平横向浮雕条纹表盘，以及垂直拉丝配镜面倒角的一体式金属链带**三大家族血脉。在 `5711/1A` 与 `5712/1A` 相继停产后，`5821` 迅速成为百达翡丽男装运动线最受瞩目的核心标的。

## 一、尺寸真知与核心结构（化解客户“45 mm 太大”顾虑）

许多客户初次看到官网标注的 `45 mm` 参数时会误以为尺寸过于夸张，这是对客沟通中**最需要第一时间纠正的尺寸认知**：

| 维度 | 实测参数与核心解读 |
| --- | --- |
| **系列归属** | Cubitus（方形运动系列 / 俗称“方形鹦鹉螺”） |
| **官方标注尺寸** | 10 点至 4 点对角线 **`45 mm`**（**并非传统圆表的左右直径！**） |
| **实际视觉与佩戴体感** | 左右边到边实际宽度约 **`44.5 mm`**，且整表厚度仅 **`8.3 mm`**（极为纤薄贴腕）；配合短促收拢的一体式表耳与贴合手腕的弧度，**实际佩戴视觉接近 41–42 mm 现代运动圆表** |
| **表壳结构与防水** | **两件式表壳结构**（前装式设计），旋入式表冠，防水 **30 米** |
| **搭载机芯** | **`Cal. 26-330 S C`** 自动上链机芯（支持停秒功能，3 点位瞬跳[日历](/general/functions/basic/date)窗）；**21K 金中央摆陀专门饰有与表盘呼应的方形水平横纹** |
| **表扣配置** | 一体式金属链带配百达翡丽专利**带锁定可微调折叠扣**（支持两侧各微调约 2 mm，应对手腕热胀冷缩） |

## 三、二手收售与验表实操要点

1. **大面积垂直拉丝表圈的抗划伤与翻新红线**
   - `5821` 的方形宽表圈正面采用大面积**精细垂直缎面拉丝**，且棱线极直，边缘带镜面抛光倒角。日常佩戴中表圈正面极易留下细微发丝划痕，但**切忌轻易打磨抛光**——方形直线拉丝一旦经过非原厂粗糙抛光，极易出现拉丝纹路歪斜、倒角塌陷变圆，直接大幅折损二手残值。
2. **核对 Cal. 26-330 S C 专属横纹摆陀**
   - 通过蓝宝石背透观察机芯时，除了核对百达翡丽印记（PP 印记）与机芯编号外，需确认其 **21K 金摆陀带有 Cubitus 专属的水平横纹雕刻**（与表盘横纹呼应），且拔出表冠调时可正常触发停秒。
3. **带锁定微调表扣与链节数量**
   - `5821/1A` 与 `5821/1AR` 均采用一体式金属链带，收表时务必清点完整链节数量（全长未拆表节对于腕围较粗的买家至关重要），并测试折叠扣两侧微调延展机构开合是否顺畅无卡滞。
