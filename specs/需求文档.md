# 腕表业务知识库需求文档

版本：0.19（需求讨论稿）  
编写日期：2026-11-16  
项目目录：`watch-knowledge-base`

## 1. 项目背景与目标

公司从事二手腕表销售。新人入职需要学习共同的业务知识，现有知识资料较少、分散，部分表述缺乏严谨性，传统讲解和纸质资料不便查阅与更新。

建设一个类似常见技术文档的知识库网站，集中呈现腕表业务知识，让员工能够系统学习、随时查询。网站面向所有岗位，不按岗位划分阅读权限或学习内容。

- 侧边目录随通用知识或当前品牌切换；手机端通过可展开的目录按钮访问。
- 首页（知识库介绍页）：直接采用带侧边目录的文档布局（不做独立门户着陆页），简短说明知识库用途、学习顺序与阅读约定，底部「下一篇」直接衔接「认识腕表结构」。

- 文章内目录：较长文章可以跳转到指定章节，手机端采用可折叠入口。
- 上一篇、下一篇：支持按目录顺序连续学习。
- 404 页面：链接不存在时，可以返回首页或继续查阅目录。

### 3.2 搜索

- 搜索标题和正文内容，结果可点击进入文章或相关章节。
- 搜索入口在手机端容易找到，结果界面使用中文。
- 用中文品牌、专业术语、数字型号和中英文混合词检验搜索效果。
- 第一版不做 AI 问答、图片识别或联网搜索。

### 3.3 图文阅读

- 支持多级标题、列表、表格、图片和文章间链接。
- 腕表细节图片应可查看清晰大图，建议提供点击放大。
- 宽表格在自身容器内横向滚动，不导致整个页面横向溢出。
- 主要文字与手机背景有足够对比度，字号与行距适合长文阅读。
- 网站名称、标识、配色暂未确定；建议先使用简洁文档主题。

### 3.4 更新时间

- 默认在每篇正式知识文章中显示最后更新时间。
- 时间表示该文章最近一次提交修改的时间，不代表鉴定结论或内容有效期。
- 建议统一使用中国标准时间（Asia/Shanghai）和中文日期格式。
- 修改其他文章或仅重新部署网站，不应改变当前文章的更新时间。
- 不需要编辑人展示、修订对比界面或独立更新日志页面。

### 4.2 通用知识（已确认）

通用知识涵盖跨品牌的结构、材质、工艺、功能和行业生态。入门内容建立基础框架；腕表功能在同一模块内按「基础功能」「实用复杂功能」「超级复杂功能」三级功能复杂度组织，由日常基础显示逐步递进至机械复杂功能。品牌特有的材质、工艺标准与功能实现仍在品牌知识中讲解。

| 顺序 | 模块 | 已确认内容 | 呈现要求 |
| --- | --- | --- | --- |
| 1 | 认识腕表结构 | 直观认识腕表组成及部件关系 | 3D 交互动画 + 文字讲解 |
| 2 | 腕表的材质 | 1 篇总览横向对比（配 2D 交互对比台）+ 6 篇单材质专章（精钢、陶瓷、黄金、玫瑰金、白金、铂金） | 覆盖佩戴相关的物理性质、化学性质与消费者心理感受；品牌独门合金与特殊复合材质留在品牌材质专章深入讲解 |
| 3 | 腕表的工艺 | 1 篇总览流派对比（配 2D 流派对照台）+ 4 篇工艺子专章（表壳加工与表面打磨、表盘制作与艺术装饰、机芯修饰与现代表面工程、宝石镶嵌工艺） | 拉通传统手工修饰（百达翡丽、爱彼）、现代精密工业（劳力士）与先锋微机械工程（理查米尔）三大流派；奠定二手抛光翻新、后镶钻与拆修痕鉴别基石；品牌独门标准留在「品牌工艺」专章 |
| 4 | 腕表功能 | 按「基础功能」「实用复杂功能」「超级复杂功能」三级功能复杂度分组，由用途识别逐步深入原理 | 基础功能与实用复杂功能图文讲解（含必要原理动画）；超级复杂功能深入原理及动画 |
| 5 | 腕表行业的生态 | 行业生态与公司业务的关系，重点讲公司关注的品牌 | 以百达翡丽、理查米尔、劳力士为主要讲解对象，少量涉及爱彼 |

**模块 1：认识腕表结构**

- 3D 交互动画属于明确需求，不能仅用静态图片代替。
- 文字应与演示中的部件名称和说明对应，帮助员工把视觉结构与术语联系起来。
- 支持旋转、缩放、点击部件高亮并查看讲解，以及展开／复原演示；交互细节通过基础样例验证，模型采用简化教学精度。
- 已确认展示范围：表壳整体、中壳、表耳、表镜、底盖、表冠、表带、表扣，以及机芯、自动陀、摆轮和游丝。表壳作为整体概念，与中壳、表耳等组成部件区分说明。
- 使用代码自行构建一个很基础的通用教学模型，把上述已确认部位演示齐全即可；不要求复刻某款腕表、精密机芯或完整机械传动。
- 以整表观察、部件展开和机芯局部放大组织演示，摆轮、游丝和自动陀可用简化运动帮助理解；以部件完整、可辨识、说明清楚为验收重点。

**模块 2：腕表的材质**

- 通用材质模块采用「1 篇总览横向对比 + 6 篇单材质专章」结构，覆盖精钢、陶瓷、黄金、玫瑰金、白金、铂金六种核心基础材质。
- 总览篇（`材质总览与对比`）嵌入 2D 交互材质多维对比台，横向比较六大材质的物理性质（密度与压手感、维氏抗刮硬度、抗冲击韧性、导热率与冬日贴肤触感）、化学性质与日常养护寿命（耐汗液腐蚀、抗氧化变色、低致敏性）以及消费者心理光谱，并拆解银白三兄弟、黄金与玫瑰金、抗刮与抗摔等高频易混点。
- 6 篇单材质专章分别深入单个材质的工艺特点、物理化学表现、消费心理画像、典型代表表款与二手验表要点；白金与铂金独立成章并重点区分，避免概念混淆。
- 品牌独门合金配方与特殊复合材质（如劳力士 904L 蚝式钢与永恒玫瑰金、理查米尔 Carbon TPT / Quartz TPT 与五级钛、百达翡丽材质尾缀编码等）留在各品牌专题的「品牌材质」专章中深入讲解，通用正文通过链接引导衔接。

**模块 3：腕表的工艺**

- 通用工艺模块采用「1 篇总览流派对比 + 4 篇工艺子专章」结构，总览篇嵌入 2D 交互流派对照台，拉通传统手工修饰流派（百达翡丽、爱彼）、现代精密工业流派（劳力士）与先锋微机械工程流派（理查米尔）的审美与技术原理。
- 4 篇子专章分别深入表壳加工与表面打磨（CNC/锻压、拉丝、镜面抛光、倒角与喷砂）、表盘制作与艺术装饰（放射纹、电镀/漆面、玑镂、大明火珐琅与镂空微机械盘面）、机芯修饰与现代表面工程（日内瓦波纹、鱼鳞纹、手工倒角内角、黑抛与微喷砂/PVD/DLC/阳极氧化等现代表面处理），以及宝石镶嵌工艺（爪镶、隐形镶、轨道镶、雪花镶与原厂/后镶鉴别）。
- 重点解决理查米尔现代微机械工程与传统高级制表的工艺差异认知，并为二手业务提供抛光翻新（抛圆/拉丝走形）、后镶钻及拆修痕鉴别的底层基石。各品牌独门印记、壳链打磨红线与珍稀手工艺暗记留在「品牌工艺」专章深入讲解。

**模块 4：腕表功能**

- 基础功能（日期、动力存储）与实用复杂功能（双时区、计时、飞返计时、年历）均配图片和简明文字，讲清名称、用途、盘面识别及基础操作（如飞返计时等带机械切换原理的功能可配动画辅助理解）。
- 入门内容不展开超出该层级需要的内部机构与传动细节；若提到更高阶复杂功能，先让新人知道其用途并链接对应专题即可。
- 跨品牌通用的超级复杂功能原理与动画集中放在「通用知识 → 腕表功能 → 超级复杂功能」；品牌或具体腕表篇章只展开其特定实现，并链接通用专题。
- 复杂功能动画优先采用二维示意，有需要时采用三维；入门内容不强制配齐复杂功能动画。

**模块 5：腕表行业的生态**

- 重点围绕公司关注的品牌，讲清其在行业中的位置及与二手业务相关的联系。
- 建议覆盖品牌、生产与供应、销售渠道、消费者、二手流通和售后服务等关系；具体边界后续细化。
- 品牌篇幅按已确认侧重安排；动态市场观察应标注观察时间，不作为实时行情服务。

### 4.3 品牌专题（已确认）

#### 组织与命名规则

- 与通用知识并列设置品牌知识栏目，按「品牌 → 热门系列 → 具体腕表」组织。
- 各品牌的「品牌材质」「品牌工艺」「型号解读」「关联型号与对比记忆」独立设置，与「热门系列」并列；劳力士额外设置「表带类型」。具体腕表页面链接相关通用知识，避免反复讲解。
- 系列名称使用官方名称，存在常用中文俗称时在括号中补充，例如 `Cubitus（方形运动系列）`。没有已确认俗称的系列不强行添加，具体官方拼写和中文名称在编写正文时核对。
- 理查米尔按用户指定的 07、35、55、65、67、72 设置教学分组；分组不等同于完整官方型号，具体腕表保留其官方完整型号，不擅自统一前导零或编号。
- 每个系列仅收录需要培训的腕表，不要求穷举品牌全部型号或在售配置。
- 具体腕表型号专章统一采用五个一级章节（`##`）标准大纲，确保全库跨品牌、跨系列的查阅体验高度一致；各章节内部子标题与表达形式按表款特点灵活安排。

#### 腕表页面与配置变种

- 默认一个基础型号对应一个讲解页面，例如「百达翡丽 → Nautilus（鹦鹉螺）→ 5711」。
- 同一页面讲解该款腕表，并展示不同配置变种；差异明显、内容较多时再拆分页面，保持相互链接。
- 用户所指的变种主要来自颜色、表带或联名差异，不把每个变种自动拆成独立文章。
- **每个收录变种（即使该基础型号目前仅设单一官方配置）均须在配置章节中单独列出完整官方型号／编号、配对版高清实拍图，并用简明扼要的篇幅单独讲解该配置的独特之处或独占特征（不重复复述前文已讲过的表壳直径、基础机芯、防水与通用操作等共用信息）**；不为没有独立编号的配色或表带组合编造编号。
- **具体腕表型号页面统一采用标准五段式一级大标题（`##`）结构**（标题下方统一配首屏代表大图）：
  1. `## 一、一眼特征盘点（视觉识别锚点）`（壳型尺寸侧键、盘面开窗与副盘坐标、背透摆陀表扣、与易混款一秒区分锚点）
  2. `## 二、功能盘点与操作逻辑`（显示项、机芯规格与停秒、表冠档位及壳侧按钮／隐藏调校孔方位、调校禁区红线）
  3. `## 三、主流配置变种图鉴`（单一配置款式为 `## 三、官方配置图鉴（全系唯一配置）`；逐款独立列出完整型号、实拍图与独特差异精讲）
  4. `## 四、本款特殊之处深度详解`（代际演进、专利机械巧思、编码特例或设计突破）
  5. `## 五、二手收售核验与行情逻辑`（验表死穴、防翻新／防后镶钻／附件清点红线与二级市场定位）
  并与品牌下的「关联型号与对比记忆（看图识表总纲）」形成“横向一秒筛型号 + 纵向五段吃透单表”的双层闭环。
- 是否纳入后配或改装配置尚未确认，不将其默认写入已确认范围。

#### 关联型号与对比记忆（已确认）

- 在品牌下设置独立分类，集中讲解有关系的两个或多个型号，帮助员工通过对比记忆；侧边栏导航中统一放在该品牌「基础必修」与各「热门系列具体型号」之后（遵循“先建立品牌基础与单表认知，最后横向对比巩固与防错”的学习顺序）。
- 以一组相关型号为一篇对比文章，可围绕同系列相近款、前后代、功能或外观相近款等组织；这些是选题方向，实际关系需核实。
- 重点说明“为什么放在一起比较”、共同点、关键差异和识别记忆要点，不只是并排罗列参数。
- 优先使用配图、差异标注、简表和简明说明；不强制每组采用统一格式。
- 对比文章与已存在的型号文章相互链接。完整型号讲解仍在型号页维护，对比页聚焦关系和差异，避免重复正文。
- 比较的是不同型号之间的关系；同款内部的颜色、表带、联名变种仍默认放在原型号页。
- 先预留分类及文章扩展结构，具体型号组合后续按需添加；没有独立型号文章时，可先写有实际内容的对比文章，不生成无效链接。

#### 品牌材质、品牌工艺、型号解读与劳力士表带

- 品牌材质章节承接通用材质的物理、化学与消费心理基础，深入讲该品牌独门合金配方、特殊复合材质（如百达翡丽材质尾缀、理查米尔 TPT 复合材质与五级钛、劳力士 904L 蚝式钢与永恒玫瑰金等）及实际型号应用，并链接通用材质知识。
- 品牌工艺章节承接通用工艺三大流派与四大工艺环节，深入讲该品牌的独门认证标准、标志性壳链打磨语言、珍稀手工艺防伪暗记、机芯修饰特征与二手品相/翻新/后镶鉴定红线（如百达翡丽 PP 印记、运动款刀锋倒角、大明火珐琅 `EMAIL` 暗记与三问总裁试听传统等）。
- 跨品牌通用的功能原理链接到腕表功能对应复杂度专题；品牌／型号页保留简短解释，并深入讲本品牌或该款的显示布局、操作方式、机芯特点和注意事项等实际差异，不复制完整原理与动画。
- 消费者态度涉及偏好、认知和接受程度等，区分客观性质与市场观察，避免将偏好写成普遍事实；具体性质结论需核实。
- 型号解读遵循「能可靠读出的信息都写出来」，不只介绍少量示例字段。
- 按各品牌实际规则说明数字、字母、分隔符和后缀的含义；系列、材质、功能、盘面、表带等信息只有在该编码确实支持判断时才列为可读结论。

- 对无法单凭型号确定的项目明确说明，不将配色、联名、生产年份等信息一概认定为可由型号解码。

### 4.4 腕表功能的内容组织（已确认）

采用「基础功能 → 实用复杂功能 → 超级复杂功能」三级功能复杂度，并衔接「品牌／型号具体实现」。功能文章归入「通用知识 → 腕表功能」，独立于品牌栏目，通用原理和动画集中维护，其他文章通过链接引用。

| 层级 | 内容范围 | 呈现方式 |
| --- | --- | --- |
| 基础功能 | 日期、动力存储 | 图片与简明文字，认识日常基础显示用途与盘面识别方式 |
| 实用复杂功能 | 双时区、计时、飞返计时、年历 | 图文结合结构与操作讲解（如飞返计时配原理动画），建立业务高频复杂功能认知 |
| 超级复杂功能 | 万年历、双秒追针计时、陀飞轮、三问、天文星象 | 独立专题文章，深入机械原理与相应动画 |
| 品牌／型号实现 | 某品牌或腕表如何实现该功能，有哪些特点与操作注意事项 | 简短功能说明、通用专题链接和特定实现讲解 |

- 型号页应保留足够的简短解释，使读者不跳转也能理解当前文章；完整原理和动画只维护一份。
- 基础功能与实用复杂功能以后需要更深入讲解时，可按需补充专题或原理动画，不把基础页不断扩写为冗长百科。
- 天文星象先作为专题分类，后续根据实际腕表拆解具体功能与演示，不预设用一个动画涵盖全部内容。
- 通用原理与动画在「通用知识 → 腕表功能」下集中维护，特定实现留在品牌／型号篇章。

## 5. 内容组织约定

- 每篇文章围绕一个明确主题，尽量先解释概念，再给示例和业务应用。
- 区分通用事实、经验判断和公司业务规则，避免把经验表述为绝对结论。
- 涉及型号差异、技术参数或品牌政策时，建议注明适用范围和参考来源。
- 未经确认的内容保留在本地资料或草稿中，不作为正式知识发布。
- 不引入编辑人员管理和系统审核流程；以上约定用于提高正文质量。
- 图片从网络搜集，记录原始来源并选用可发布的素材；3D 模型通过代码自行构建，模型代码纳入 Git 管理。
